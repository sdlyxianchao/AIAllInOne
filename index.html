Quick Start

Two ways to deploy. The AI Agent method is recommended — it reads the deployment guide, asks you for parameters, and configures everything automatically.

Method 1: AI Agent Deployment (Recommended)

Install any AI coding agent (WorkBuddy, OpenClaw, Claude Code, etc.), point it at the repository, and let it deploy the entire platform for you.

# Step 1: Clone the repository
git clone https://github.com/sdlyxianchao/AIAllInOne
cd AIAllInOne/windows

# Step 2: Install the deploy skill (one-time)
# Copy AIOperation/agent/ to your agent's skills directory
# e.g. ~/.workbuddy/skills/ai-all-in-one-ops/

# Step 3: Tell your AI agent to deploy
# Just say: "Deploy AI AllInOne"
# The agent will:
# → Read the deployment guide
# → Ask you for server IP, admin password, API keys
# → Configure .env, start containers
# → Initialize Keycloak, NewAPI, Dify, Ghost, Gitea
# → Run health checks and verify everything works

Method 2: Manual Deployment

# Clone and configure
git clone https://github.com/sdlyxianchao/AIAllInOne
cd AIAllInOne/windows
cp .env.windows .env && nano .env

# Create network and start
docker network create ai-platform
docker compose up -d

# Then follow the deployment guide to initialize
# each service (Keycloak, NewAPI, Dify, etc.)

Supports Windows (Docker Desktop), Linux (Ubuntu 24.04+), and offline deployment (pre-built Docker images included).
