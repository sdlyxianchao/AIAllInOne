# AI AllInOne User Manual

*Version 0.2 · Employee Usage Guide*

This manual is the employee (end-user) guide to the company's intranet AI platform. It explains the three entry points, how to use the two tools (DeepChat and Dify), how to request an API key, and the data security policy and code of conduct you need to follow. Each chapter page has previous/next navigation at the bottom — read through from start to finish, or jump straight to the topic you need.
