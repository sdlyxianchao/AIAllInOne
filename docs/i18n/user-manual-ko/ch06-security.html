데이터 보안 규정

AI에 무엇을 보내도 되고 무엇을 절대 보내면 안 되는지——모두가 지켜야 할 레드라인.

플랫폼은 이미 휴대폰번호, 주민등록번호, 은행카드 번호, 이메일 등 민감 정보를 비식별화하고 (대형 모델에 보내기 전 자동 마스킹), 민감어를 차단합니다. 하지만 아래 레드라인을 자발적으로 준수하세요.

6.1 무엇을 보내도 되고 무엇을 보내면 안 되는가

❌ AI에 보내면 안 되는 것

  • 내부 기밀 / 영업 기밀 (미공개 제품 코드, 가격, 고객 목록, 계약 조항);
  • 개인정보 (주민등록번호, 은행카드 번호, 비밀번호, 건강 정보, 타인 프라이버시);
  • 소스 코드 / 미공개 기술 방안.

✅ 안심하고 사용 가능

  • 공개 자료, 일반 지식, 문서 작성, 번역, 요약;
  • 비식별화된 업무 데이터 (구체적 인명/번호/민감 필드 제거 후).

6.2 데이터 등급 빠른 참조

내부 일반 데이터⚠️ 비식별화 후 사용 가능민감 필드 제거 후 사용 가능
