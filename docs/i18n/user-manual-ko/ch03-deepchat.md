## 3.1 다운로드 및 설치

1. 포털 다운로드 센터 `http://IP:8090/downloads/` 열기;

2. 시스템에 따라 설치 패키지 다운로드 후 설치;

3. DeepChat 실행.

## 3.2 모델 설정 (회사 게이트웨이 연결)

최초 사용 시 DeepChat에 모델 위치를 알려줘야 합니다. 회사가 모델을 게이트웨이 **NewAPI**로 통합 수용했으므로, 세 값만 입력하면 됩니다:

**1.** DeepChat 열기 → 좌측 하단 **설정 (⚙️)** → **모델 서비스 / 모델 공급자**.

**2.** 「**사용자 지정 Provider**」 또는 「**OpenAI 호환**」 추가.

**3.** 아래 세 항목 입력:

| 필드 | 무엇을 입력 |
| --- | --- |
| API Base URL | `http://IP:3000/v1` |
| API Key | NewAPI에서 신청한 `sk-` 키 (제5장 참조) |
| 모델 | `deepseek-chat` (회사 기본, 기타 개방된 모델 선택 가능) |

**4.** 저장.

> ⚠️ **핵심**: API Base URL은 반드시 **내부망 IP** (`http://IP:3000/v1`) 사용, `localhost` 사용 금지, 아니면 회사 서버에 연결되지 않습니다.

## 3.3 대화 시작

1. 「**+ 새 대화**」 클릭;

2. 입력창에 타이핑, 엔터로 전송;

3. 응답 수신 시 링크 정상.

> 💡 **한번 해보세요**: 「고객에게 보내는 정중한 독촉 메일을 써줘, 톤은 부드럽게」를 보내 AI 답변 확인. 이어서 「아래 문장을 영어로 번역해줘: ……」도 시도. DeepChat은 다중 턴 대화를 지원하므로 계속 추궁하거나 AI에게 수정 요청 가능.

## 3.4 자주 쓰는 기능 및 팁

| 기능 | 사용법 |
| --- | --- |
| 다중 모델 전환 | 대화 상단에서 다른 모델 선택 (회사가 여러 개 개방한 경우) |
| 파일 읽기/쓰기 / MCP 도구 | 설정 → MCP에서 회사 도구 (예: 파일 시스템) 활성화, AI가 로컬 파일 읽기 |
| 다크/라이트 테마 | 설정 → 디자인 |
| 네트워크 프록시 문제 | 「연결 타임아웃」 오류 → 설정 → 네트워크/프록시 → 「프록시 사용 안 함/직접 연결」로 변경 |

## 3.5 질문 팁

> ✅ **구체적일수록 좋습니다**——배경 제공, 요구 명확히, 예시 제공, AI 답변 품질이 높아집니다.

> 💡 좋은 예: 「당신은 시니어 카피라이터입니다. CTO 독자 대상, 전문적이고 절제된 톤으로 200자 제품 소개를 써줘」——「소개 써줘」보다 훨씬 낫습니다.

- **역할 부여**: 「당신은 재무 전문가입니다, ...도와주세요」;

- **제약 부여**: 「100자 이내로 / 표로 / 세 단계로」;

- **예시 부여**: 「이 형식을 참고해 다시 써줘……」;

- **단계별 추궁**: 만족스럽지 않으면 「다시 고쳐줘」「톤을 바꿔줘」.
