## 7.1 로그인 / 접속

| 질문 | 해결 |
| --- | --- |
| 특정 제품에 로그인 안 됨? | 내부망 IP (localhost 아님) 및 통합 계정 사용 확인; 그래도 안 되면 관리자에게 문의 |
| 로그인 페이지가 안 열림 / 계속 로딩? | 회사 내부망 (WiFi/유선) 연결 확인, 주소는 `http://IP` 사용 (localhost 아님) |
| 통합 계정 비밀번호 분실? | 관리자에게 재설정 요청 (또는 도메인 계정으로 복구) |

## 7.2 사용

| 질문 | 해결 |
| --- | --- |
| 할당량 부족 안내? | NewAPI 백오피스에서 잔액 확인; 소진 시 관리자에게 충전/증액 요청 |
| 전송 내용이 차단됨? | 민감어 또는 민감 정보에 해당, 제6장 규정에 따라 조정 후 재시도 |
| DeepChat 연결 타임아웃? | 설정 → 네트워크/프록시 → 「프록시 사용 안 함/직접 연결」로 변경 |
| 모델 응답 품질이 낮음? | 다른 모델로 변경, 또는 질문 최적화 (맥락 제공, 요구 명확히, 예시 제공) |
| DeepChat 다운로드 위치를 잊음? | 포털 다운로드 센터 `http://IP:8090/downloads/` |
| Dify 앱 생성 시 계속 로딩? | 보통 네트워크/WebSocket 문제, 관리자에게 문의; 브라우저 Ctrl+F5 강력 새로고침 |

## 7.3 인식

| 질문 | 해결 |
| --- | --- |
| AI 답변을 믿어도 되나요? | 전부 믿으면 안 됩니다. AI는 틀릴 수 있고(환각), 중요한 사실, 숫자, 코드는 반드시 사람이 검증 |
| AI가 내가 한 말을 기억하나요? | 현재 대화 맥락은 다중 턴 응답을 위해 보존되므로 기밀 정보를 입력하지 마세요 (제6장 참조) |
