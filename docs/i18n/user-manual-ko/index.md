# AI AllInOne 사용자 매뉴얼

*v0.2 · 직원 사용 가이드*

이 매뉴얼은 회사 인트라넷 AI 플랫폼의 직원(최종 사용자)용 가이드입니다. 세 가지 진입점, 두 도구(DSH Desktop 및 Dify) 사용법, API 키 신청 방법, 그리고 준수해야 할 데이터 보안 정책과 행동 강령을 설명합니다. 각 장 페이지 하단에 이전/다음 내비게이션이 있습니다.
