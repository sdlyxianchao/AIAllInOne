# AI AllInOne Manual del usuario

*v0.2 · Guía de uso para empleados*

Este manual es la guía del empleado (usuario final) para la plataforma de IA de la intranet de la empresa. Explica los tres puntos de entrada, el uso de las dos herramientas (DSH Desktop y Dify), cómo solicitar una clave API, y la política de seguridad de datos y el código de conducta que debe seguir. Cada capítulo tiene navegación anterior/siguiente al final de la página.
