データセキュリティ規程

何を AI に送ってよいか、何を絶対に送ってはならないか——全員が守るべき一線。

プラットフォームは携帯番号、身分証番号、銀行カード番号、メールなどの機密情報を自動でマスキングし（大規模モデル送信前に自動で伏字化）、機密語をブロックします。ただし、以下の一線は自覚して守ってください。

6.1 送ってよいもの、送ってはいけないもの

❌ AI への送信を厳禁

  • 内部機密 / 商業機密（未公開の製品コード、価格、顧客リスト、契約条項）；
  • 個人プライバシー（身分証番号、銀行カード番号、パスワード、健康情報、他者のプライバシー）；
  • ソースコード / 未公開の技術方案。

✅ 安心して利用できるもの

  • 公開資料、一般知識、文書作成、翻訳、要約；
  • マスキング後の業務データ（具体的な人名/番号/機密フィールドを除去したもの）。

6.2 データ分類クイックリファレンス

データ等級外部大規模モデルへ送信可か説明
公開データ✅ 可公開済みの資料、一般情報
内部一般データ⚠️ マスキング後に可機密フィールドを除去すれば利用可
内部機密 / 個人プライバシー❌ 禁止送信厳禁
判断基準：「この内容が外部の人の目に触れたら問題があるか？」ある → 送らない。

6.3 3 つの典型的なシーン

シーンどうするか
週報作成で顧客名が関わる「ある顧客」「A 顧客」で実際の顧客名を代替
AI にデータ表を分析させる先に氏名、電話、身分証番号などの列を削除し、集計データのみ残す
契約条項の翻訳先に金額、相手方名称などの機密情報を削除、または「甲/乙」で代替
