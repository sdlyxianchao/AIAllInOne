## 8.1 使用規範

- 不用於違法違規用途，不生成違法、有害、侵權內容；

- 不繞過平台安全限制，不批次刷額度；

- 對外傳送 AI 生成內容時，核實事實並遵守公司資訊釋出規範；

- 妥善保管自己的 API Key，不轉借他人、不提交到程式碼倉庫；

- 發現異常（帳號異常、內容異常）及時報告管理員。

## 8.2 一句話總結

> ✅ 善用 AI 提效，但**機密不發、事實必核、規矩要守**。有問題聯絡平台管理員。
