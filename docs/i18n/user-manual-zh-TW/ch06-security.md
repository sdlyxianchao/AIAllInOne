平台已自動對**手機號、身分證號、銀行卡號、郵箱**等敏感資訊做**遮蔽**（發給大模型前自動打碼），並對敏感詞做攔截。但請自覺遵守下面的紅線。

## 6.1 什麼能發什麼不能發

### ❌ 嚴禁傳送給 AI

- 內部機密 / 商業機密（未公開的產品程式碼、定價、客戶名單、合同條款）；

- 個人隱私（身分證號、銀行卡號、密碼、健康資訊、他人隱私）；

- 原始碼 / 未公開技術方案。

### ✅ 可以放心使用

- 公開資料、通用知識、文件撰寫、翻譯、總結；

- 遮蔽後的業務資料（去掉具體人名/號碼/敏感欄位後）。

## 6.2 資料分級速查

| 資料等級 | 能否上外部大模型 | 說明 |
| --- | --- | --- |
| 公開資料 | ✅ 可以 | 已公開的資料、通用資訊 |
| 內部普通資料 | ⚠️ 遮蔽後可用 | 去掉敏感欄位後可使用 |
| 內部機密 / 個人隱私 | ❌ 禁止 | 嚴禁傳送 |

判斷原則：**「這段內容如果被外人看到會不會有問題？」**會 → 別發。

## 6.3 三個典型場景

| 場景 | 怎麼做 |
| --- | --- |
| 寫週報，涉及客戶名 | 用「某客戶」「A 客戶」代替真實客戶名 |
| 讓 AI 分析資料表 | 先刪掉姓名、電話、身分證號等列，只留彙總資料 |
| 翻譯合同條款 | 先刪掉金額、對方名稱等敏感資訊，或用「甲方/乙方」代替 |
