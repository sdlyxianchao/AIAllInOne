快速開始

工具二：Dify

Web AI 應用平台：用現成應用、建知識庫問答。

4.1 登入 Dify

  1. 瀏覽器開啟 http://IP（80 埠，無埠號；也可從門戶「AI 工作臺」點進來）；
  2. 用統一帳號登入（首次可能需管理員先開通帳號）。

4.2 用現成的聊天應用

管理員會預先搭好一些應用（如「公司制度問答」「客服助手」），普通使用者直接「用」即可：

  1. 登入後進入「工作室 / 應用」列表；
  2. 找到要用的應用，點「執行 / 預覽」（右上角播放鍵）；
  3. 在開啟的對話頁直接提問。

4.3 知識庫問答

想把內部文件「喂」給 AI 讓它回答，用 Dify 的知識庫（需管理員給權限）：

  1. 「知識庫」→「建立知識庫」；
  2. 上傳文件（支援 Word / PDF / Markdown / 網頁連結等）；
  3. 系統自動分段、建索引；
  4. 在應用裡「引用」這個知識庫，AI 就能基於你的文件回答。
📌 知識庫內容會被 AI 用於回答，請遵守第 6 章資料安全規範——不要上傳機密資料。

4.4 自己搭一個簡單應用（進階）

  1. 工作室 → 建立空白應用 → 選「聊天助手」；
  2. 寫一段「提示詞」告訴 AI 它的角色（如「你是公司考勤制度答疑助手」）；
  3. 加知識庫 → 選模型 → 預覽測試 → 釋出。
