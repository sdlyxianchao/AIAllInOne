# AI AllInOne 使用者手冊

*v0.2 · 員工使用指南*

**快速開始**

## 1. 認識平台

> 📌 說明：本手冊裡的 `IP` 指公司內網伺服器地址（示例 `192.168.31.117`，實際以管理員公佈為準）。所有地址都用**內網 IP**，不要用 `localhost` 或 `127.0.0.1`。
### 1.1 平台是什麼
「AI AllInOne」是公司內網部署的一套企業 AI 平台，把大模型（DeepSeek、GPT、Claude 等）的能力統一收口到內網，員工**一個帳號**就能用。你不需要關心背後的伺服器、模型、金鑰——只需要記住三個入口。
### 1.2 我能用平台做什麼
| 想做什麼 | 用哪個 | 在哪開啟 |
| --- | --- | --- |
| 像 ChatGPT 一樣日常對話、寫文件、翻譯、改程式碼 | 💬 DeepChat | 桌面客戶端（先從門戶下載安裝） |
| 用公司搭好的 AI 應用（客服問答、審批助手等） | 🤖 Dify | 瀏覽器 `http://IP` |
| 上傳文件做「知識庫問答」（問內部資料） | 🤖 Dify | 瀏覽器 `http://IP` |
| 看公司新聞、公告、下載軟體 | 📰 門戶（Hub） | 瀏覽器 `http://IP:8090` |
| 自己申請 API Key 接第三方工具 | 🔑 NewAPI | 瀏覽器 `http://IP:3000` |
### 1.3 三個入口怎麼選
> ✅ **一句話記住**：**聊天/寫作/翻譯 → DeepChat**；**公司搭好的應用/知識庫 → Dify**；**找東西/看公告/下軟體 → 門戶 Hub**。三個都用同一個帳號登入。
登入方式：所有產品都走 **Keycloak 統一帳號**（部分支援公司 AD 網域帳號，即你電腦開機那套帳號）。點「登入」自動跳統一登入頁，輸一次帳號，之後各產品無需重複登入。
### 1.4 本手冊怎麼用
- **新手**：按順序讀第 2~4 章，先裝上 DeepChat 用起來；
- **要接第三方工具**：讀第 5 章申請 Key；
- **有疑問**：先查第 7 章 FAQ，再問管理員；
- **必讀**：第 6 章資料安全、第 8 章行為準則，人人都要遵守。

## 2. AI All In One Hub（門戶）

### 2.1 門戶是什麼
Ghost**AI All In One Hub** 是公司的企業門戶（基於開源軟體 Ghost 搭建），地址 `http://IP:8090`。它是你進入 AI 平台的**起點**。
### 2.2 看新聞 / 公告
1. 瀏覽器開啟 `http://IP:8090`；
2. 首頁就是最新新聞、公告列表，點標題讀全文。
### 2.3 下載中心（裝 DeepChat）
1. 點門戶頂部「**下載中心**」選單，或直接開啟 `http://IP:8090/downloads/`；
2. 按系統選 **Windows** / **macOS** 安裝包，下載 **DeepChat**；
3. 安裝：Windows 雙擊 .exe 按嚮導；macOS 開啟 .dmg 拖進「應用程式」。
> ✅ 下載頁頂部「首次使用先裝技能管家」是給高階使用者的技能包，普通使用者可忽略。
### 2.4 跳轉到 Dify / 幫助
- 點門戶選單「**AI 工作臺**」→ 直接跳 Dify（AI 應用平台）；
- 點「**幫助文件**」→ 檢視公司整理的幫助文章。
> 📖 原廠文件：門戶由 Ghost 提供，官方文件 https://ghost.org/docs/

## 3. 工具一：DeepChat

### 3.1 下載與安裝
1. 開啟門戶下載中心 `http://IP:8090/downloads/`；
2. 按系統下載安裝包並安裝；
3. 啟動 DeepChat。
### 3.2 配置模型（連公司閘道器）
首次使用需要告訴 DeepChat 模型在哪。公司已把模型統一收口到閘道器 **NewAPI**，你只需填三個值：
1開啟 DeepChat → 左下角 **設定（⚙️）** → **模型服務 / 模型提供商**。
2新增「**自定義 Provider**」或「**OpenAI 相容**」。
3填入以下三項：
| 欄位 | 填什麼 |
| --- | --- |
| API Base URL | `http://IP:3000/v1` |
| API Key | 在 NewAPI 申請的 `sk-` 金鑰（見第 5 章） |
| 模型 | `deepseek-chat`（公司預設，可選其它已開放模型） |
4儲存。
> ⚠️ **關鍵**：API Base URL 必須用**內網 IP**（`http://IP:3000/v1`），不要用 `localhost`，否則連不上公司伺服器。
### 3.3 開始對話
1. 點「**+ 新建對話**」；
2. 輸入框打字，Enter傳送；
3. 收到回覆即鏈路正常。
### 💡 **試一試**：傳送「幫我寫一封給客戶的催款郵件，語氣委婉」看 AI 如何回答。再試試「把下面這段話翻譯成英文：……」。DeepChat 支援多輪對話，可繼續追問、讓 AI 修改。

    3.4 常用功能與技巧
| 功能 | 怎麼用 |
| --- | --- |
| 多模型切換 | 對話頂部選不同模型（若公司開放多個） |
| 檔案讀寫 / MCP 工具 | 設定 → MCP 啟用公司工具（如檔案系統），讓 AI 讀本地檔案 |
| 深色/淺色主題 | 設定 → 外觀 |
| 網路代理問題 | 報「連線超時」→ 設定 → 網路/代理 → 改為「不使用代理/直連」 |
### 3.5 提問技巧
> ✅ **越具體越好**——提供背景、說清要求、給示例，AI 回答質量更高。
- 💡 好例子：「你是資深文案，幫我寫一段 200 字的產品介紹，面向 CTO 讀者，風格專業剋制」——比「寫個介紹」好得多。
    
      **給角色**：「你是一名財務專家，幫我……」；
- **給約束**：「控制在 100 字以內 / 用表格 / 分三步」；
- **給示例**：「參照這個格式改寫……」；
- **分步追問**：不滿意就「再改改」「換個語氣」。
> 📖 原廠文件：DeepChat 快速開始 https://deepchatai.cn/docs/guide/getting-started/ · 開源倉庫 https://github.com/ThinkInAIXYZ/deepchat

## 4. 工具二：Dify

### 4.1 登入 Dify
1. 瀏覽器開啟 `http://IP`（80 埠，無埠號；也可從門戶「AI 工作臺」點進來）；
2. 用統一帳號登入（首次可能需管理員先開通帳號）。
### 4.2 用現成的聊天應用
管理員會預先搭好一些應用（如「公司制度問答」「客服助手」），普通使用者直接「用」即可：
1. 登入後進入「**工作室 / 應用**」列表；
2. 找到要用的應用，點「**執行 / 預覽**」（右上角播放鍵）；
3. 在開啟的對話頁直接提問。
### 4.3 知識庫問答
想把內部文件「喂」給 AI 讓它回答，用 Dify 的**知識庫**（需管理員給權限）：
1. 「**知識庫**」→「建立知識庫」；
2. 上傳文件（支援 Word / PDF / Markdown / 網頁連結等）；
3. 系統自動分段、建索引；
4. 在應用裡「引用」這個知識庫，AI 就能基於你的文件回答。
> 📌 知識庫內容會被 AI 用於回答，請遵守第 6 章資料安全規範——**不要上傳機密資料**。
### 4.4 自己搭一個簡單應用（進階）
1. 工作室 → 建立空白應用 → 選「聊天助手」；
2. 寫一段「提示詞」告訴 AI 它的角色（如「你是公司考勤制度答疑助手」）；
3. 加知識庫 → 選模型 → 預覽測試 → 釋出。
> 📖 原廠文件：Dify 官方文件 https://docs.dify.ai

## 5. 申請 API Key

如果你要把公司的 AI 能力接入**第三方工具**（自己的指令碼、其它支援 OpenAI 介面的軟體），需要一個 API Key（`sk-` 開頭的金鑰）。
### 5.1 登入 NewAPI
1. 瀏覽器開啟 `http://IP:3000`；
2. 用統一帳號登入（或點「一鍵登入 / OIDC」用網域帳號）。
### 5.2 新建令牌
1. 左側選單「**API 金鑰 / 令牌**」；
2. 點「**新建令牌**」，起名（如 `我的指令碼`），可設額度、過期時間；
3. 儲存後複製生成的 `sk-xxxx` 字串。**只顯示一次，務必立即儲存**。
### 5.3 填入客戶端
- **API Base URL**：`http://IP:3000/v1`
- **API Key**：剛才複製的 `sk-xxxx`
### 5.4 常見用法示例
> 💡 用 curl 測試：  
> 
>     `curl http://IP:3000/v1/chat/completions -H "Authorization: Bearer sk-xxxx" -H "Content-Type: application/json" -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"你好"}]}'`
> 
>     ⚠️ 額度用完後報「餘額不足」，聯絡管理員申請提額。Key 相當於你的帳號密碼，**不要發給別人、不要提交到程式碼倉庫**。
> 📖 原廠文件：NewAPI 官方文件 https://docs.newapi.pro · 官網 https://www.newapi.ai

## 6. 資料安全規範

平台已自動對**手機號、身分證號、銀行卡號、郵箱**等敏感資訊做**遮蔽**（發給大模型前自動打碼），並對敏感詞做攔截。但請自覺遵守下面的紅線。
### 6.1 什麼能發什麼不能發
#### ❌ 嚴禁傳送給 AI
- 內部機密 / 商業機密（未公開的產品程式碼、定價、客戶名單、合同條款）；
- 個人隱私（身分證號、銀行卡號、密碼、健康資訊、他人隱私）；
- 原始碼 / 未公開技術方案。
#### ✅ 可以放心使用
- 公開資料、通用知識、文件撰寫、翻譯、總結；
- 遮蔽後的業務資料（去掉具體人名/號碼/敏感欄位後）。
### 6.2 資料分級速查
| 資料等級 | 能否上外部大模型 | 說明 |
| --- | --- | --- |
| 公開資料 | ✅ 可以 | 已公開的資料、通用資訊 |
| 內部普通資料 | ⚠️ 遮蔽後可用 | 去掉敏感欄位後可使用 |
| 內部機密 / 個人隱私 | ❌ 禁止 | 嚴禁傳送 |
> > 判斷原則：**「這段內容如果被外人看到會不會有問題？」**會 → 別發。
### 6.3 三個典型場景
| 場景 | 怎麼做 |
| --- | --- |
| 寫週報，涉及客戶名 | 用「某客戶」「A 客戶」代替真實客戶名 |
| 讓 AI 分析資料表 | 先刪掉姓名、電話、身分證號等列，只留彙總資料 |
| 翻譯合同條款 | 先刪掉金額、對方名稱等敏感資訊，或用「甲方/乙方」代替 |

## 7. 常見問題 FAQ

### 7.1 登入 / 訪問類
| 問題 | 解決 |
| --- | --- |
| 登入不上某個產品？ | 確認用內網 IP（不是 localhost）且用統一帳號；仍不行聯絡管理員 |
| 登入頁面打不開 / 一直轉圈？ | 確認連的是公司內網（WiFi/有線），地址用 `http://IP` 而非 localhost |
| 忘記統一帳號密碼？ | 聯絡管理員重置（或走網域帳號找回） |
### 7.2 使用類
| 問題 | 解決 |
| --- | --- |
| 提示額度不足？ | NewAPI 後臺查餘額；用完聯絡管理員充值/提額 |
| 傳送內容被攔截？ | 命中了敏感詞或含敏感資訊，按第 6 章規範調整後重試 |
| DeepChat 報連線超時？ | 設定 → 網路/代理 → 改為「不使用代理/直連」 |
| 模型回覆質量差？ | 換不同模型，或最佳化提問（提供上下文、明確要求、給示例） |
| 忘了在哪下 DeepChat？ | 門戶下載中心 `http://IP:8090/downloads/` |
| Dify 建立應用一直轉圈？ | 通常是網路/WebSocket 問題，聯絡管理員；瀏覽器 Ctrl+F5 強刷 |
### 7.3 認知類
| 問題 | 解決 |
| --- | --- |
| AI 的回答能信嗎？ | 不能全信。AI 可能出錯（幻覺），重要事實、數字、程式碼務必人工核實 |
| AI 會記住我說的話嗎？ | 當前對話上下文會被保留用於多輪迴答，請勿輸入機密資訊（見第 6 章） |

## 8. 行為準則

### 8.1 使用規範
- 不用於違法違規用途，不生成違法、有害、侵權內容；
- 不繞過平台安全限制，不批次刷額度；
- 對外傳送 AI 生成內容時，核實事實並遵守公司資訊釋出規範；
- 妥善保管自己的 API Key，不轉借他人、不提交到程式碼倉庫；
- 發現異常（帳號異常、內容異常）及時報告管理員。
### 8.2 一句話總結
> ✅ 善用 AI 提效，但**機密不發、事實必核、規矩要守**。有問題聯絡平台管理員。
