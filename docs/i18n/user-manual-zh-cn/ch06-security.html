数据安全规范

什么能发给 AI、什么绝不能发——人人都要遵守的红线。

平台已自动对手机号、身份证号、银行卡号、邮箱等敏感信息做脱敏（发给大模型前自动打码），并对敏感词做拦截。但请自觉遵守下面的红线。

6.1 什么能发什么不能发

❌ 严禁发送给 AI

  • 内部机密 / 商业机密（未公开的产品代码、定价、客户名单、合同条款）；
  • 个人隐私（身份证号、银行卡号、密码、健康信息、他人隐私）；
  • 源代码 / 未公开技术方案。

✅ 可以放心使用

  • 公开资料、通用知识、文档撰写、翻译、总结；
  • 脱敏后的业务数据（去掉具体人名/号码/敏感字段后）。

6.2 数据分级速查

数据等级能否上外部大模型说明
公开数据✅ 可以已公开的资料、通用信息
内部普通数据⚠️ 脱敏后可用去掉敏感字段后可使用
内部机密 / 个人隐私❌ 禁止严禁发送
判断原则：「这段内容如果被外人看到会不会有问题？」会 → 别发。

6.3 三个典型场景

场景怎么做
写周报，涉及客户名用「某客户」「A 客户」代替真实客户名
让 AI 分析数据表先删掉姓名、电话、身份证号等列，只留汇总数据
翻译合同条款先删掉金额、对方名称等敏感信息，或用「甲方/乙方」代替
