# Manual do Usuário do AI AllInOne

*v0.2 · Guia de uso para funcionários*

Este manual é o guia do funcionário (usuário final) para a plataforma de IA da intranet da empresa. Explica os três pontos de entrada, como usar as duas ferramentas (DSH Desktop e Dify), como solicitar uma chave de API e a política de segurança de dados e o código de conduta que você deve seguir. Cada capítulo tem navegação anterior/próximo na parte inferior.
