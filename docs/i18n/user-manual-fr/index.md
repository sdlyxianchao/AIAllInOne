# Manuel de l'utilisateur AI AllInOne

*v0.2 · Guide de l'employé*

Ce manuel est le guide de l'employé (utilisateur final) de la plateforme IA intranet de l'entreprise. Il explique les trois points d'entrée, l'utilisation des deux outils (DSH Desktop et Dify), la demande d'une clé API, ainsi que la politique de sécurité des données et le code de conduite à respecter. Chaque chapitre dispose d'une navigation précédent/suivant en bas de page.
