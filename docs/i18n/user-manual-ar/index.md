# دليل مستخدم AI AllInOne

*v0.2 · دليل استخدام الموظفين*

هذا الدليل هو دليل الموظف (المستخدم النهائي) لمنصة الذكاء الاصطناعي على الشبكة الداخلية للشركة. يشرح نقاط الدخول الثلاث، وكيفية استخدام الأداتين (DSH Desktop وDify)، وكيفية طلب مفتاح API، وسياسة أمن البيانات ومدونة قواعد السلوك التي يجب الالتزام بها. يحتوي كل فصل على تنقّل سابق/تالي أسفل الصفحة.

| 2 | [AI All In One Hub (البوابة)](ch02-hub.md) | نقطة البداية للدخول إلى منصة الذكاء الاصطناعي: قراءة الأخبار وتنزيل البرامج والانتقال إلى Dify. |
| 3 | [الأداة الأولى: DSH Desktop](ch03-dsh.md) | عميل سطح مكتب لمحادثات الذكاء الاصطناعي: التنزيل والإعداد والمحادثة والنصائح المتقدمة. |
| 4 | [الأداة الثانية: Dify](ch04-dify.md) | منصة تطبيقات ذكاء اصطناعي عبر الويب: استخدام التطبيقات الجاهزة وبناء أسئلة وأجوبة من قاعدة معرفية. |
