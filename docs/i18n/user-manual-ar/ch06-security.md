# الفصل 6: ضوابط أمن البيانات

*البداية السريعة*

> ما الذي يمكن إرساله إلى الذكاء الاصطناعي وما الذي يُمنع إرساله مطلقًا — خط أحمر يجب على الجميع الالتزام به.

تتعامل المنصة تلقائيًا مع المعلومات الحساسة مثل **أرقام الهاتف وبطاقات الهوية والبطاقات المصرفية والبريد الإلكتروني** عبر **إخفائها** (تُشوَّش تلقائيًا قبل إرسالها إلى النموذج الكبير)، كما تعترض الكلمات الحساسة. لكن يرجى الالتزام طوعًا بالخطوط الحمراء التالية.

## 6.1 ما الذي يمكن وما الذي لا يمكن إرساله

### ❌ يُمنع إرساله إلى الذكاء الاصطناعي منعًا باتًا

- الأسرار الداخلية / التجارية (أكواد المنتجات غير المنشورة والتسعير وقوائم العملاء وبنود العقود)؛

- الخصوصية الشخصية (رقم بطاقة الهوية ورقم البطاقة المصرفية وكلمات المرور والمعلومات الصحية وخصوصية الآخرين)؛

- الكود المصدري / الحلول التقنية غير المنشورة.

### ✅ يمكن استخدامه بأمان

- المواد العامة والمعرفة الشائعة وكتابة المستندات والترجمة والتلخيص؛

- بيانات الأعمال بعد إخفائها (بعد إزالة الأسماء/الأرقام/الحقول الحساسة).

## 6.2 مرجع سريع لتصنيف البيانات

| مستوى البيانات | هل يمكن إرسالها إلى النموذج الكبير الخارجي | الوصف |
| --- | --- | --- |
| البيانات العامة | ✅ نعم | المواد المنشورة والمعلومات العامة |
| البيانات الداخلية العادية | ⚠️ يمكن بعد الإخفاء | تُستخدم بعد إزالة الحقول الحساسة |
| الأسرار الداخلية / الخصوصية الشخصية | ❌ ممنوع | يُمنع الإرسال منعًا باتًا |

مبدأ التقييم: **«هل يسبب هذا المحتوى مشكلة إذا رآه شخص خارجي؟»** إذا كان الجواب نعم ← فلا ترسله.

## 6.3 ثلاثة سيناريوهات نموذجية

| السيناريو | ماذا تفعل |
| --- | --- |
| كتابة تقرير أسبوعي يتضمن اسم عميل | استخدم «عميل معين» أو «العميل A» بدلًا من الاسم الحقيقي |
| طلب تحليل جدول بيانات من الذكاء الاصطناعي | احذف أولًا أعمدة الأسماء والهواتف وأرقام الهوية وأبقِ البيانات الملخصة فقط |
| ترجمة بنود عقد | احذف أولًا المعلومات الحساسة مثل المبالغ وأسماء الأطراف، أو استخدم «الطرف الأول/الطرف الثاني» بدلًا منها |
