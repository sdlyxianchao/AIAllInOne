## 7.1 فئة تسجيل الدخول / الوصول

| المشكلة | الحل |
| --- | --- |
| تعذّر تسجيل الدخول إلى أحد المنتجات؟ | تأكد من استخدام عنوان IP الداخلي (وليس localhost) والحساب الموحد؛ وإن استمرت المشكلة فتواصل مع المدير |
| صفحة تسجيل الدخول لا تفتح / تدور باستمرار؟ | تأكد من اتصالك بالشبكة الداخلية للشركة (WiFi/سلكي)، واستخدم العنوان `http://IP` وليس localhost |
| نسيت كلمة مرور الحساب الموحد؟ | تواصل مع المدير لإعادة تعيينها (أو استرجعها عبر حساب النطاق) |

## 7.2 فئة الاستخدام

| المشكلة | الحل |
| --- | --- |
| تظهر رسالة رصيد غير كافٍ؟ | تحقق من الرصيد في لوحة NewAPI؛ وعند نفاده تواصل مع المدير للشحن/رفع الحصة |
| حُظر المحتوى المرسل؟ | أصاب كلمة حساسة أو يحتوي معلومات حساسة؛ عدّله وفق ضوابط الفصل 6 ثم أعد المحاولة |
| يظهر انتهاء مهلة الاتصال في DSH Desktop؟ | الإعدادات ← الشبكة/الوكيل ← غيّرها إلى «بدون وكيل/اتصال مباشر» |
| جودة رد النموذج ضعيفة؟ | جرّب نموذجًا مختلفًا أو حسّن صياغة السؤال (قدّم السياق ووضّح المتطلبات وأعطِ أمثلة) |
| نسيت مكان تنزيل DSH Desktop؟ | مركز التنزيلات في البوابة `http://IP:8090/downloads/` |
| يدور Dify باستمرار عند إنشاء تطبيق؟ | عادة تكون مشكلة شبكة/WebSocket؛ تواصل مع المدير، وأعد تحميل المتصفح بقوة عبر Ctrl+F5 |

## 7.3 فئة الإدراك/الوعي

| المشكلة | الحل |
| --- | --- |
| هل يمكن الوثوق بإجابات الذكاء الاصطناعي؟ | لا يمكن الوثوق بها كليًا؛ فقد يخطئ الذكاء الاصطناعي (هلوسة)، ويجب التحقق يدويًا من الحقائق والأرقام والأكواد المهمة |
| هل يحفظ الذكاء الاصطناعي ما أقوله؟ | يُحتفظ بسياق المحادثة الحالية للإجابة متعددة الجولات، لذا لا تُدخل معلومات سرية (انظر الفصل 6) |
