## 3.1 التنزيل والتثبيت

1. افتح مركز التنزيلات في البوابة `http://IP:8090/downloads/`؛

2. نزّل حزمة التثبيت المناسبة لنظامك وثبّتها؛

3. شغّل DSH Desktop.

## 3.2 إعداد النموذج (الاتصال ببوابة الشركة)

عند أول استخدام تحتاج إلى إخبار DSH Desktop بمكان النموذج. لقد جمعت الشركة النماذج في بوابة واحدة هي **NewAPI**، وما عليك سوى تعبئة ثلاث قيم:

**1.** افتح DSH Desktop ← أسفل اليسار **الإعدادات (⚙️)** ← **خدمة النماذج / مزوّدو النماذج**.

**2.** أضف «**مزوّد مخصص**» أو «**متوافق مع OpenAI**».

**3.** املأ العناصر الثلاثة التالية:

| الحقل | ما الذي تكتبه |
| --- | --- |
| API Base URL | `http://IP:3000/v1` |
| API Key | مفتاح `sk-` الذي طلبته من NewAPI (انظر الفصل 5) |
| النموذج | `deepseek-chat` (الافتراضي للشركة، ويمكن اختيار نماذج أخرى مفتوحة) |

**4.** احفظ.

> ⚠️ **مهم**: يجب استخدام **عنوان IP الداخلي** في API Base URL (`http://IP:3000/v1`) وليس `localhost`، وإلا فلن تتمكن من الاتصال بخادم الشركة.

## 3.3 بدء المحادثة

1. انقر على «**+ محادثة جديدة**»؛

2. اكتب في مربع الإدخال واضغط Enter للإرسال؛

3. عند وصول الرد فهذا يعني أن المسار يعمل بشكل سليم.

> 💡 **جرّب**: أرسل «اكتب لي رسالة مطالبة بالدفع لعميل بأسلوب مهذب» وشاهد كيف يجيب الذكاء الاصطناعي. وجرّب أيضًا «ترجم الفقرة التالية إلى الإنجليزية: ……». يدعم DSH Desktop المحادثات متعددة الجولات، ويمكنك المتابعة بأسئلة إضافية وطلب تعديل الإجابة من الذكاء الاصطناعي.

## 3.4 الوظائف والحيل الشائعة

| الوظيفة | كيفية الاستخدام |
| --- | --- |
| تبديل النماذج | اختر نموذجًا مختلفًا أعلى المحادثة (إن كانت الشركة تفتح عدة نماذج) |
| أدوات قراءة/كتابة الملفات / MCP | الإعدادات ← MCP لتفعيل أدوات الشركة (مثل نظام الملفات) ليتسنى للذكاء الاصطناعي قراءة الملفات المحلية |
| الوضع الداكن/الفاتح | الإعدادات ← المظهر |
| مشكلة وكيل الشبكة | عند ظهور «انتهاء مهلة الاتصال» ← الإعدادات ← الشبكة/الوكيل ← غيّرها إلى «بدون وكيل/اتصال مباشر» |

## 3.5 نصائح لطرح الأسئلة

> ✅ **كلما كان السؤال أكثر تحديدًا كان أفضل** — قدّم الخلفية ووضّح المتطلبات وأعطِ أمثلة لتحصل على إجابات أجود.

> 💡 مثال جيد: «أنت كاتب محتوى محترف، اكتب لي مقدمة منتج من 200 كلمة موجّهة إلى جمهور مدراء التقنية CTO بأسلوب مهني متزن» — وهذا أفضل بكثير من مجرد «اكتب مقدمة».

- **حدّد الدور**: «أنت خبير مالي، ساعدني في...»؛

- **حدّد القيود**: «في حدود 100 كلمة / استخدم جدولًا / قسّمها إلى ثلاث خطوات»؛

- **أعطِ مثالًا**: «أعد الصياغة وفق هذا التنسيق...»؛

- **تابع خطوة بخطوة**: إن لم يعجبك الرد فاطلب «عدّل مرة أخرى» أو «غيّر النبرة».
