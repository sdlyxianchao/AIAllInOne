# دليل مستخدم AI AllInOne

*v0.2 · دليل استخدام الموظفين*

**البداية السريعة**

## 1. التعرّف على المنصة

> 📌 ملاحظة: يشير `IP` في هذا الدليل إلى عنوان خادم الشبكة الداخلية للشركة (المثال `192.168.31.117`، والعنوان الفعلي هو ما يعلنه المدير). استخدم **عنوان IP الداخلي** في جميع العناوين، ولا تستخدم `localhost` أو `127.0.0.1`.
### 1.1 ما هي المنصة
«AI AllInOne» هي منصة ذكاء اصطناعي مؤسسية منشورة على شبكة الشركة الداخلية، تجمع قدرات النماذج الكبيرة (DeepSeek وGPT وClaude وغيرها) في نقطة واحدة داخلية، بحيث يكفي الموظف **حساب واحد** لاستخدامها. لست بحاجة للاهتمام بالخوادم أو النماذج أو المفاتيح خلف الكواليس — يكفي أن تتذكر ثلاثة مداخل.
### 1.2 ماذا يمكنني أن أفعل بالمنصة
| ماذا تريد أن تفعل | أيهما تستخدم | أين تفتحه |
| --- | --- | --- |
| محادثات يومية وكتابة مستندات وترجمة وتعديل أكواد مثل ChatGPT | 💬 DeepChat | عميل سطح المكتب (نزّله وثبّته من البوابة أولًا) |
| استخدام تطبيقات الذكاء الاصطناعي التي أعدتها الشركة (إجابة العملاء ومساعد الموافقات وغيرها) | 🤖 Dify | المتصفح `http://IP` |
| رفع مستندات لإنشاء «أسئلة وأجوبة من قاعدة معرفية» (للسؤال عن المواد الداخلية) | 🤖 Dify | المتصفح `http://IP` |
| الاطلاع على أخبار الشركة والإعلانات وتنزيل البرامج | 📰 البوابة (Hub) | المتصفح `http://IP:8090` |
| طلب مفتاح API بنفسك لربطه بأدوات خارجية | 🔑 NewAPI | المتصفح `http://IP:3000` |
### 1.3 كيف تختار بين المداخل الثلاثة
> ✅ **تذكّر في جملة واحدة**: **المحادثة/الكتابة/الترجمة ← DeepChat**؛ و**التطبيقات التي أعدتها الشركة/قاعدة المعرفة ← Dify**؛ و**البحث/الاطلاع على الإعلانات/تنزيل البرامج ← بوابة Hub**. الثلاثة تستخدم الحساب نفسه لتسجيل الدخول.
طريقة تسجيل الدخول: تستخدم جميع المنتجات **حساب Keycloak الموحد** (وبعضها يدعم حساب نطاق AD الخاص بالشركة، أي الحساب الذي تسجّل به دخول جهازك). عند النقر على «تسجيل الدخول» ستنتقل تلقائيًا إلى صفحة الدخول الموحدة، وأدخل الحساب مرة واحدة فقط، فلن تحتاج بعدها لإعادة تسجيل الدخول في كل منتج.
### 1.4 كيف تستخدم هذا الدليل
- **المبتدئ**: اقرأ الفصول 2~4 بالترتيب وثبّت DeepChat أولًا لتبدأ استخدامه؛
- **لربط أدوات خارجية**: اقرأ الفصل 5 لطلب المفتاح؛
- **عند وجود استفسار**: راجع أولًا الأسئلة الشائعة في الفصل 7 ثم اسأل المدير؛
- **مطلوب قراءته**: الفصل 6 الخاص بأمن البيانات والفصل 8 الخاص بمدونة السلوك، ويجب على الجميع الالتزام بهما.

## 2. AI All In One Hub (البوابة)

### 2.1 ما هي البوابة
Ghost**AI All In One Hub** هي بوابة الشركة المؤسسية (المبنية على البرنامج مفتوح المصدر Ghost) وعنوانها `http://IP:8090`. وهي **نقطة البداية** لدخول منصة الذكاء الاصطناعي.
### 2.2 قراءة الأخبار / الإعلانات
1. افتح `http://IP:8090` في المتصفح؛
2. الصفحة الرئيسية هي قائمة أحدث الأخبار والإعلانات، وانقر على العنوان لقراءة النص كاملًا.
### 2.3 مركز التنزيلات (تثبيت DeepChat)
1. انقر على قائمة «**مركز التنزيلات**» أعلى البوابة، أو افتح مباشرة `http://IP:8090/downloads/`؛
2. اختر حزمة التثبيت المناسبة لنظامك **Windows** / **macOS** ونزّل **DeepChat**؛
3. التثبيت: في Windows انقر نقرًا مزدوجًا على .exe واتبع المعالج؛ وفي macOS افتح .dmg واسحبه إلى «التطبيقات».
> ✅ حزمة «ثبّت مدير المهارات أولًا عند أول استخدام» أعلى صفحة التنزيل مخصصة للمستخدمين المتقدمين، ويمكن للمستخدم العادي تجاهلها.
### 2.4 الانتقال إلى Dify / المساعدة
- انقر على قائمة «**منضدة عمل AI**» في البوابة ← للانتقال مباشرة إلى Dify (منصة تطبيقات الذكاء الاصطناعي)؛
- انقر على «**مستندات المساعدة**» ← للاطلاع على مقالات المساعدة التي أعدتها الشركة.
> 📖 الوثائق الرسمية:البوابة مقدمة عبر Ghost، والوثائق الرسمية https://ghost.org/docs/

## 3. الأداة الأولى: DeepChat

### 3.1 التنزيل والتثبيت
1. افتح مركز التنزيلات في البوابة `http://IP:8090/downloads/`؛
2. نزّل حزمة التثبيت المناسبة لنظامك وثبّتها؛
3. شغّل DeepChat.
### 3.2 إعداد النموذج (الاتصال ببوابة الشركة)
عند أول استخدام تحتاج إلى إخبار DeepChat بمكان النموذج. لقد جمعت الشركة النماذج في بوابة واحدة هي **NewAPI**، وما عليك سوى تعبئة ثلاث قيم:
1افتح DeepChat ← أسفل اليسار **الإعدادات (⚙️)** ← **خدمة النماذج / مزوّدو النماذج**.
2أضف «**مزوّد مخصص**» أو «**متوافق مع OpenAI**».
3املأ العناصر الثلاثة التالية:
| الحقل | ما الذي تكتبه |
| --- | --- |
| API Base URL | `http://IP:3000/v1` |
| API Key | مفتاح `sk-` الذي طلبته من NewAPI (انظر الفصل 5) |
| النموذج | `deepseek-chat` (الافتراضي للشركة، ويمكن اختيار نماذج أخرى مفتوحة) |
4احفظ.
> ⚠️ **مهم**: يجب استخدام **عنوان IP الداخلي** في API Base URL (`http://IP:3000/v1`) وليس `localhost`، وإلا فلن تتمكن من الاتصال بخادم الشركة.
### 3.3 بدء المحادثة
1. انقر على «**+ محادثة جديدة**»؛
2. اكتب في مربع الإدخال واضغط Enter للإرسال؛
3. عند وصول الرد فهذا يعني أن المسار يعمل بشكل سليم.
### 💡 **جرّب**: أرسل «اكتب لي رسالة مطالبة بالدفع لعميل بأسلوب مهذب» وشاهد كيف يجيب الذكاء الاصطناعي. وجرّب أيضًا «ترجم الفقرة التالية إلى الإنجليزية: ……». يدعم DeepChat المحادثات متعددة الجولات، ويمكنك المتابعة بأسئلة إضافية وطلب تعديل الإجابة من الذكاء الاصطناعي.

    3.4 الوظائف والحيل الشائعة
| الوظيفة | كيفية الاستخدام |
| --- | --- |
| تبديل النماذج | اختر نموذجًا مختلفًا أعلى المحادثة (إن كانت الشركة تفتح عدة نماذج) |
| أدوات قراءة/كتابة الملفات / MCP | الإعدادات ← MCP لتفعيل أدوات الشركة (مثل نظام الملفات) ليتسنى للذكاء الاصطناعي قراءة الملفات المحلية |
| الوضع الداكن/الفاتح | الإعدادات ← المظهر |
| مشكلة وكيل الشبكة | عند ظهور «انتهاء مهلة الاتصال» ← الإعدادات ← الشبكة/الوكيل ← غيّرها إلى «بدون وكيل/اتصال مباشر» |
### 3.5 نصائح لطرح الأسئلة
> ✅ **كلما كان السؤال أكثر تحديدًا كان أفضل** — قدّم الخلفية ووضّح المتطلبات وأعطِ أمثلة لتحصل على إجابات أجود.
- 💡 مثال جيد: «أنت كاتب محتوى محترف، اكتب لي مقدمة منتج من 200 كلمة موجّهة إلى جمهور مدراء التقنية CTO بأسلوب مهني متزن» — وهذا أفضل بكثير من مجرد «اكتب مقدمة».
    
      **حدّد الدور**: «أنت خبير مالي، ساعدني في...»؛
- **حدّد القيود**: «في حدود 100 كلمة / استخدم جدولًا / قسّمها إلى ثلاث خطوات»؛
- **أعطِ مثالًا**: «أعد الصياغة وفق هذا التنسيق...»؛
- **تابع خطوة بخطوة**: إن لم يعجبك الرد فاطلب «عدّل مرة أخرى» أو «غيّر النبرة».
> 📖 الوثائق الرسمية:البداية السريعة لـ DeepChat https://deepchatai.cn/docs/guide/getting-started/ · المستودع مفتوح المصدر https://github.com/ThinkInAIXYZ/deepchat

## 4. الأداة الثانية: Dify

### 4.1 تسجيل الدخول إلى Dify
1. افتح `http://IP` في المتصفح (المنفذ 80 دون رقم منفذ؛ ويمكن الدخول أيضًا من «منضدة عمل AI» في البوابة)؛
2. سجّل الدخول بالحساب الموحد (قد يحتاج المدير إلى إنشاء حسابك أولًا عند أول استخدام).
### 4.2 استخدام تطبيقات المحادثة الجاهزة
سيُعدّ المدير مسبقًا بعض التطبيقات (مثل «أسئلة وأجوبة عن لوائح الشركة» و«مساعد خدمة العملاء»)، وما على المستخدم العادي إلا «استخدامها» مباشرة:
1. بعد تسجيل الدخول ادخل إلى قائمة «**الاستوديو / التطبيقات**»؛
2. ابحث عن التطبيق المطلوب وانقر على «**تشغيل / معاينة**» (زر التشغيل أعلى اليمين)؛
3. اطرح سؤالك مباشرة في صفحة المحادثة المفتوحة.
### 4.3 أسئلة وأجوبة من قاعدة المعرفة
لإدخال المستندات الداخلية إلى الذكاء الاصطناعي ليجيب عنها، استخدم **قاعدة المعرفة** في Dify (يتطلب منح الصلاحية من المدير):
1. «**قاعدة المعرفة**» ← «إنشاء قاعدة معرفة»؛
2. ارفع المستندات (تدعم Word / PDF / Markdown / روابط صفحات ويب وغيرها)؛
3. يقسمها النظام تلقائيًا ويبني فهرسًا لها؛
4. استشهد بهذه القاعدة داخل التطبيق ليتمكن الذكاء الاصطناعي من الإجابة بناءً على مستنداتك.
> 📌 ستُستخدم محتويات قاعدة المعرفة في إجابات الذكاء الاصطناعي، فالتزم بضوابط أمن البيانات في الفصل 6 — **لا ترفع مستندات سرية**.
### 4.4 بناء تطبيق بسيط بنفسك (متقدم)
1. الاستوديو ← إنشاء تطبيق فارغ ← اختر «مساعد محادثة»؛
2. اكتب «موجهًا» يخبر الذكاء الاصطناعي بدوره (مثل «أنت مساعد الإجابة عن لوائح الحضور والانصراف في الشركة»)؛
3. أضف قاعدة المعرفة ← اختر النموذج ← جرّب المعاينة ← انشر.
> 📖 الوثائق الرسمية:وثائق Dify الرسمية https://docs.dify.ai

## 5. طلب مفتاح API

إذا أردت ربط قدرات الذكاء الاصطناعي للشركة بـ**أدوات خارجية** (سكربتاتك الخاصة أو برامج أخرى تدعم واجهة OpenAI)، فستحتاج إلى مفتاح API (مفتاح يبدأ بـ `sk-`).
### 5.1 تسجيل الدخول إلى NewAPI
1. افتح `http://IP:3000` في المتصفح؛
2. سجّل الدخول بالحساب الموحد (أو انقر على «تسجيل دخول بضغطة واحدة / OIDC» لاستخدام حساب النطاق).
### 5.2 إنشاء رمز جديد
1. من القائمة اليسرى «**مفاتيح API / الرموز**»؛
2. انقر على «**رمز جديد**» وسمِّه (مثل `سكربتي`) ويمكنك تعيين الحصة وتاريخ الانتهاء؛
3. بعد الحفظ انسخ سلسلة `sk-xxxx` المولّدة. **تُعرض مرة واحدة فقط فاحفظها فورًا**.
### 5.3 تعبئة القيم في العميل
- **API Base URL**: `http://IP:3000/v1`
- **مفتاح API**: `sk-xxxx` الذي نسخته للتو
### 5.4 أمثلة على الاستخدام الشائع
> 💡 الاختبار باستخدام curl:   
> 
>     `curl http://IP:3000/v1/chat/completions -H "Authorization: Bearer sk-xxxx" -H "Content-Type: application/json" -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"مرحبًا"}]}'`
> 
>     ⚠️ عند نفاد الحصة تظهر رسالة «رصيد غير كافٍ»؛ تواصل مع المدير لطلب رفع الحصة. المفتاح يعادل كلمة مرور حسابك، لذا **لا ترسله لأي شخص ولا ترفعه إلى مستودعات الأكواد**.
> 📖 الوثائق الرسمية:وثائق NewAPI الرسمية https://docs.newapi.pro · الموقع الرسمي https://www.newapi.ai

## 6. ضوابط أمن البيانات

تتعامل المنصة تلقائيًا مع المعلومات الحساسة مثل **أرقام الهاتف وبطاقات الهوية والبطاقات المصرفية والبريد الإلكتروني** عبر **إخفائها** (تُشوَّش تلقائيًا قبل إرسالها إلى النموذج الكبير)، كما تعترض الكلمات الحساسة. لكن يرجى الالتزام طوعًا بالخطوط الحمراء التالية.
### 6.1 ما الذي يمكن وما الذي لا يمكن إرساله
#### ❌ يُمنع إرساله إلى الذكاء الاصطناعي منعًا باتًا
- الأسرار الداخلية / التجارية (أكواد المنتجات غير المنشورة والتسعير وقوائم العملاء وبنود العقود)؛
- الخصوصية الشخصية (رقم بطاقة الهوية ورقم البطاقة المصرفية وكلمات المرور والمعلومات الصحية وخصوصية الآخرين)؛
- الكود المصدري / الحلول التقنية غير المنشورة.
#### ✅ يمكن استخدامه بأمان
- المواد العامة والمعرفة الشائعة وكتابة المستندات والترجمة والتلخيص؛
- بيانات الأعمال بعد إخفائها (بعد إزالة الأسماء/الأرقام/الحقول الحساسة).
### 6.2 مرجع سريع لتصنيف البيانات
| مستوى البيانات | هل يمكن إرسالها إلى النموذج الكبير الخارجي | الوصف |
| --- | --- | --- |
| البيانات العامة | ✅ نعم | المواد المنشورة والمعلومات العامة |
| البيانات الداخلية العادية | ⚠️ يمكن بعد الإخفاء | تُستخدم بعد إزالة الحقول الحساسة |
| الأسرار الداخلية / الخصوصية الشخصية | ❌ ممنوع | يُمنع الإرسال منعًا باتًا |
> > مبدأ التقييم: **«هل يسبب هذا المحتوى مشكلة إذا رآه شخص خارجي؟»** إذا كان الجواب نعم ← فلا ترسله.
### 6.3 ثلاثة سيناريوهات نموذجية
| السيناريو | ماذا تفعل |
| --- | --- |
| كتابة تقرير أسبوعي يتضمن اسم عميل | استخدم «عميل معين» أو «العميل A» بدلًا من الاسم الحقيقي |
| طلب تحليل جدول بيانات من الذكاء الاصطناعي | احذف أولًا أعمدة الأسماء والهواتف وأرقام الهوية وأبقِ البيانات الملخصة فقط |
| ترجمة بنود عقد | احذف أولًا المعلومات الحساسة مثل المبالغ وأسماء الأطراف، أو استخدم «الطرف الأول/الطرف الثاني» بدلًا منها |

## 7. الأسئلة الشائعة FAQ

### 7.1 فئة تسجيل الدخول / الوصول
| المشكلة | الحل |
| --- | --- |
| تعذّر تسجيل الدخول إلى أحد المنتجات؟ | تأكد من استخدام عنوان IP الداخلي (وليس localhost) والحساب الموحد؛ وإن استمرت المشكلة فتواصل مع المدير |
| صفحة تسجيل الدخول لا تفتح / تدور باستمرار؟ | تأكد من اتصالك بالشبكة الداخلية للشركة (WiFi/سلكي)، واستخدم العنوان `http://IP` وليس localhost |
| نسيت كلمة مرور الحساب الموحد؟ | تواصل مع المدير لإعادة تعيينها (أو استرجعها عبر حساب النطاق) |
### 7.2 فئة الاستخدام
| المشكلة | الحل |
| --- | --- |
| تظهر رسالة رصيد غير كافٍ؟ | تحقق من الرصيد في لوحة NewAPI؛ وعند نفاده تواصل مع المدير للشحن/رفع الحصة |
| حُظر المحتوى المرسل؟ | أصاب كلمة حساسة أو يحتوي معلومات حساسة؛ عدّله وفق ضوابط الفصل 6 ثم أعد المحاولة |
| يظهر انتهاء مهلة الاتصال في DeepChat؟ | الإعدادات ← الشبكة/الوكيل ← غيّرها إلى «بدون وكيل/اتصال مباشر» |
| جودة رد النموذج ضعيفة؟ | جرّب نموذجًا مختلفًا أو حسّن صياغة السؤال (قدّم السياق ووضّح المتطلبات وأعطِ أمثلة) |

| يدور Dify باستمرار عند إنشاء تطبيق؟ | عادة تكون مشكلة شبكة/WebSocket؛ تواصل مع المدير، وأعد تحميل المتصفح بقوة عبر Ctrl+F5 |
### 7.3 فئة الإدراك/الوعي
| المشكلة | الحل |

| هل يحفظ الذكاء الاصطناعي ما أقوله؟ | يُحتفظ بسياق المحادثة الحالية للإجابة متعددة الجولات، لذا لا تُدخل معلومات سرية (انظر الفصل 6) |

## 8. مدونة السلوك

### 8.1 ضوابط الاستخدام
- لا تستخدمها لأغراض غير قانونية أو مخالفة للوائح، ولا تولّد محتوى غير قانوني أو ضارًا أو ينتهك الحقوق؛
- لا تتجاوز القيود الأمنية للمنصة ولا تستهلك الحصص بشكل جماعي تعسفي؛
- عند إرسال محتوى يولّده الذكاء الاصطناعي خارجيًا، تحقق من الحقائق والتزم بضوابط نشر المعلومات في الشركة؛
- احفظ مفتاح API الخاص بك جيدًا، ولا تعره للآخرين ولا ترفعه إلى مستودعات الأكواد؛
- أبلغ المدير فورًا عند رصد أي أمر غير طبيعي (سواء في الحساب أو المحتوى).
### 8.2 خلاصة في جملة واحدة
> ✅ استفد من الذكاء الاصطناعي لرفع الكفاءة، لكن **لا ترسل الأسرار، وتحقق من الحقائق، والتزم بالقواعد**. تواصل مع مدير المنصة عند وجود أي مشكلة.
