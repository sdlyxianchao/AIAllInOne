*v0.2 · 직원 사용 가이드*

## 1. 플랫폼 알아보기

> 📌 안내: 본 매뉴얼의 `IP`는 회사 내부망 서버 주소를 의미합니다 (예시 `192.168.31.117`, 실제는 관리자가 공지한 값 기준). 모든 주소는 **내부망 IP**를 사용하고, `localhost`나 `127.0.0.1`을 사용하지 마세요.
### 1.1 플랫폼이란
「AI AllInOne」은 회사 내부망에 배포된 기업 AI 플랫폼으로, 대형 모델 (DeepSeek, GPT, Claude 등)의 능력을 내부망으로 통합 수용하여 직원이 **계정 하나**로 사용할 수 있게 합니다. 뒤에 있는 서버, 모델, 키를 신경 쓸 필요 없이——세 가지 진입점만 기억하면 됩니다.
### 1.2 플랫폼으로 무엇을 할 수 있나
| 하고 싶은 것 | 무엇을 쓸까 | 어디서 열까 |
| --- | --- | --- |
| ChatGPT처럼 일상 대화, 문서 작성, 번역, 코드 수정 | 💬 DeepChat | 데스크톱 클라이언트 (먼저 포털에서 다운로드 설치) |
| 회사가 만든 AI 앱 사용 (고객 Q&A, 승인 어시스턴트 등) | 🤖 Dify | 브라우저 `http://IP` |
| 문서 업로드로 「지식베이스 Q&A」 (내부 자료 질문) | 🤖 Dify | 브라우저 `http://IP` |
| 회사 뉴스, 공지, 소프트웨어 다운로드 | 📰 포털 (Hub) | 브라우저 `http://IP:8090` |
| 직접 API Key 신청해 서드파티 도구 연결 | 🔑 NewAPI | 브라우저 `http://IP:3000` |
### 1.3 세 가지 진입점 선택 방법
> ✅ **한 문장으로 기억**: **채팅/작성/번역 → DeepChat**; **회사가 만든 앱/지식베이스 → Dify**; **찾기/공지 확인/소프트웨어 다운로드 → 포털 Hub**. 세 가지 모두 같은 계정으로 로그인.
로그인 방식: 모든 제품은 **Keycloak 통합 계정**을 사용합니다 (일부는 회사 AD 도메인 계정, 즉 컴퓨터 부팅 시 쓰는 그 계정 지원). 「로그인」 클릭 시 자동으로 통합 로그인 페이지로 이동하며, 계정을 한 번 입력하면 이후 각 제품에서 재로그인이 필요 없습니다.
### 1.4 본 매뉴얼 사용법
- **초보자**: 제2~4장을 순서대로 읽고, 먼저 DeepChat을 설치해 사용하세요;
- **서드파티 도구 연결**: 제5장을 읽어 Key를 신청하세요;
- **궁금한 점**: 먼저 제7장 FAQ를 확인하고, 그래도 모르면 관리자에게 문의하세요;
- **필독**: 제6장 데이터 보안, 제8장 행동 수칙, 모두가 준수해야 합니다.

## 2. AI All In One Hub (포털)

### 2.1 포털이란
Ghost**AI All In One Hub**는 회사의 기업 포털입니다 (오픈소스 소프트웨어 Ghost 기반 구축), 주소 `http://IP:8090`. AI 플랫폼에 들어가는 **시작점**입니다.
### 2.2 뉴스 / 공지 보기
1. 브라우저에서 `http://IP:8090` 열기;
2. 홈이 최신 뉴스, 공지 목록, 제목 클릭해 전문 읽기.
### 2.3 다운로드 센터 (DeepChat 설치)
1. 포털 상단 「**다운로드 센터**」 메뉴 클릭, 또는 `http://IP:8090/downloads/` 직접 열기;
2. 시스템에 따라 **Windows** / **macOS** 설치 패키지 선택, **DeepChat** 다운로드;
3. 설치: Windows는 .exe 더블클릭 후 마법사 진행; macOS는 .dmg 열어 「응용 프로그램」으로 드래그.
> ✅ 다운로드 페이지 상단의 「처음 사용 시 먼저 스킬 매니저 설치」는 고급 사용자용 스킬 패키지로, 일반 사용자는 무시해도 됩니다.
### 2.4 Dify / 도움말로 이동
- 포털 메뉴 「**AI 워크벤치**」 클릭 → 바로 Dify (AI 앱 플랫폼)로 이동;
- 「**도움말**」 클릭 → 회사가 정리한 도움말 문서 확인.
> 📖 원문 문서:포털은 Ghost가 제공, 공식 문서 https://ghost.org/docs/

## 3. 도구 1: DeepChat

### 3.1 다운로드 및 설치
1. 포털 다운로드 센터 `http://IP:8090/downloads/` 열기;
2. 시스템에 따라 설치 패키지 다운로드 후 설치;
3. DeepChat 실행.
### 3.2 모델 설정 (회사 게이트웨이 연결)
최초 사용 시 DeepChat에 모델 위치를 알려줘야 합니다. 회사가 모델을 게이트웨이 **NewAPI**로 통합 수용했으므로, 세 값만 입력하면 됩니다:
1DeepChat 열기 → 좌측 하단 **설정 (⚙️)** → **모델 서비스 / 모델 공급자**.
2「**사용자 지정 Provider**」 또는 「**OpenAI 호환**」 추가.
3아래 세 항목 입력:
| 필드 | 무엇을 입력 |
| --- | --- |
| API Base URL | `http://IP:3000/v1` |
| API Key | NewAPI에서 신청한 `sk-` 키 (제5장 참조) |
| 모델 | `deepseek-chat` (회사 기본, 기타 개방된 모델 선택 가능) |
4저장.
> ⚠️ **핵심**: API Base URL은 반드시 **내부망 IP** (`http://IP:3000/v1`) 사용, `localhost` 사용 금지, 아니면 회사 서버에 연결되지 않습니다.
### 3.3 대화 시작
1. 「**+ 새 대화**」 클릭;
2. 입력창에 타이핑, 엔터로 전송;
3. 응답 수신 시 링크 정상.
### 💡 **한번 해보세요**: 「고객에게 보내는 정중한 독촉 메일을 써줘, 톤은 부드럽게」를 보내 AI 답변 확인. 이어서 「아래 문장을 영어로 번역해줘: ……」도 시도. DeepChat은 다중 턴 대화를 지원하므로 계속 추궁하거나 AI에게 수정 요청 가능.

    3.4 자주 쓰는 기능 및 팁
| 기능 | 사용법 |
| --- | --- |
| 다중 모델 전환 | 대화 상단에서 다른 모델 선택 (회사가 여러 개 개방한 경우) |
| 파일 읽기/쓰기 / MCP 도구 | 설정 → MCP에서 회사 도구 (예: 파일 시스템) 활성화, AI가 로컬 파일 읽기 |
| 다크/라이트 테마 | 설정 → 디자인 |
| 네트워크 프록시 문제 | 「연결 타임아웃」 오류 → 설정 → 네트워크/프록시 → 「프록시 사용 안 함/직접 연결」로 변경 |
### 3.5 질문 팁
> ✅ **구체적일수록 좋습니다**——배경 제공, 요구 명확히, 예시 제공, AI 답변 품질이 높아집니다.
- 💡 좋은 예: 「당신은 시니어 카피라이터입니다. CTO 독자 대상, 전문적이고 절제된 톤으로 200자 제품 소개를 써줘」——「소개 써줘」보다 훨씬 낫습니다.
    
      **역할 부여**: 「당신은 재무 전문가입니다, ...도와주세요」;
- **제약 부여**: 「100자 이내로 / 표로 / 세 단계로」;
- **예시 부여**: 「이 형식을 참고해 다시 써줘……」;
- **단계별 추궁**: 만족스럽지 않으면 「다시 고쳐줘」「톤을 바꿔줘」.
> 📖 원문 문서:DeepChat 빠른 시작 https://deepchatai.cn/docs/guide/getting-started/ · 오픈소스 저장소 https://github.com/ThinkInAIXYZ/deepchat

## 4. 도구 2: Dify

### 4.1 Dify 로그인
1. 브라우저에서 `http://IP` 열기 (80 포트, 포트 번호 없음; 포털 「AI 워크벤치」에서 들어갈 수도 있음);
2. 통합 계정으로 로그인 (최초에는 관리자가 먼저 계정을 개설해야 할 수 있음).
### 4.2 기존 채팅 앱 사용
관리자가 미리 몇 가지 앱 (예: 「회사 제도 Q&A」「고객 서비스 어시스턴트」)을 만들어 두므로, 일반 사용자는 바로 「사용」하면 됩니다:
1. 로그인 후 「**스튜디오 / 앱**」 목록 진입;
2. 사용할 앱 찾기, 「**실행 / 미리보기**」 클릭 (우측 상단 재생 버튼);
3. 열린 대화 페이지에서 바로 질문.
### 4.3 지식베이스 Q&A
내부 문서를 AI에 「먹여」 답변하게 하려면 Dify의 **지식베이스** 사용 (관리자 권한 필요):
1. 「**지식베이스**」 → 「지식베이스 생성」;
2. 문서 업로드 (Word / PDF / Markdown / 웹 링크 등 지원);
3. 시스템이 자동 분할, 인덱스 구축;
4. 앱에서 이 지식베이스를 「참조」하면 AI가 문서 기반으로 답변.
> 📌 지식베이스 내용은 AI 답변에 사용되므로 제6장 데이터 보안 규정을 준수하세요——**기밀 자료를 업로드하지 마세요**.
### 4.4 직접 간단한 앱 만들기 (고급)
1. 스튜디오 → 빈 앱 생성 → 「채팅 어시스턴트」 선택;
2. 「프롬프트」를 작성해 AI에 역할 부여 (예: 「당신은 회사 근태 제도 Q&A 어시스턴트입니다」);
3. 지식베이스 추가 → 모델 선택 → 미리보기 테스트 → 게시.
> 📖 원문 문서:Dify 공식 문서 https://docs.dify.ai

## 5. API Key 신청

회사의 AI 능력을 **서드파티 도구** (본인 스크립트, 기타 OpenAI 인터페이스 지원 소프트웨어)에 연결하려면 API Key (`sk-`로 시작하는 키)가 필요합니다.
### 5.1 NewAPI 로그인
1. 브라우저에서 `http://IP:3000` 열기;
2. 통합 계정으로 로그인 (또는 「원클릭 로그인 / OIDC」로 도메인 계정 사용).
### 5.2 토큰 생성
1. 좌측 메뉴 「**API 키 / 토큰**」;
2. 「**새 토큰 생성**」 클릭, 이름 지정 (예: `내-스크립트`), 할당량, 만료 시간 설정 가능;
3. 저장 후 생성된 `sk-xxxx` 문자열 복사. **한 번만 표시되므로 반드시 즉시 저장**.
### 5.3 클라이언트에 입력
- **API Base URL**: `http://IP:3000/v1`
- **API Key**: 방금 복사한 `sk-xxxx`
### 5.4 자주 쓰는 사용 예시
> 💡 curl로 테스트:  
> 
>     `curl http://IP:3000/v1/chat/completions -H "Authorization: Bearer sk-xxxx" -H "Content-Type: application/json" -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"안녕하세요"}]}'`
> 
>     ⚠️ 할당량 소진 시 「잔액 부족」 오류, 관리자에게 증액 요청. Key는 본인 계정 비밀번호와 같으므로 **다른 사람에게 주지 말고, 코드 저장소에 커밋하지 마세요**.
> 📖 원문 문서:NewAPI 공식 문서 https://docs.newapi.pro · 공식 웹사이트 https://www.newapi.ai

## 6. 데이터 보안 규정

플랫폼은 이미 **휴대폰번호, 주민등록번호, 은행카드 번호, 이메일** 등 민감 정보를 **비식별화**하고 (대형 모델에 보내기 전 자동 마스킹), 민감어를 차단합니다. 하지만 아래 레드라인을 자발적으로 준수하세요.
### 6.1 무엇을 보내도 되고 무엇을 보내면 안 되는가
#### ❌ AI에 보내면 안 되는 것
- 내부 기밀 / 영업 기밀 (미공개 제품 코드, 가격, 고객 목록, 계약 조항);
- 개인정보 (주민등록번호, 은행카드 번호, 비밀번호, 건강 정보, 타인 프라이버시);
- 소스 코드 / 미공개 기술 방안.
#### ✅ 안심하고 사용 가능
- 공개 자료, 일반 지식, 문서 작성, 번역, 요약;
- 비식별화된 업무 데이터 (구체적 인명/번호/민감 필드 제거 후).
### 6.2 데이터 등급 빠른 참조
| 데이터 등급 | 외부 대형 모델 전송 가능 여부 | 설명 |
| --- | --- | --- |
| 공개 데이터 | ✅ 가능 | 이미 공개된 자료, 일반 정보 |
| 내부 일반 데이터 | ⚠️ 비식별화 후 사용 가능 | 민감 필드 제거 후 사용 가능 |
| 내부 기밀 / 개인정보 | ❌ 금지 | 전송 엄격 금지 |
> > 판단 원칙: **「이 내용을 외부인이 보면 문제가 될까?」** 문제가 된다 → 보내지 마세요.
### 6.3 세 가지 대표 시나리오
| 시나리오 | 어떻게 할까 |
| --- | --- |
| 주간 보고 작성, 고객명 포함 | 「고객사」「A 고객」으로 실제 고객명 대체 |
| AI로 데이터 표 분석 | 먼저 이름, 전화번호, 주민등록번호 등 열을 삭제하고 요약 데이터만 남김 |
| 계약 조항 번역 | 먼저 금액, 상대방 명칭 등 민감 정보를 삭제하거나 「갑/을」로 대체 |

## 7. 자주 묻는 질문 FAQ

### 7.1 로그인 / 접속
| 질문 | 해결 |
| --- | --- |
| 특정 제품에 로그인 안 됨? | 내부망 IP (localhost 아님) 및 통합 계정 사용 확인; 그래도 안 되면 관리자에게 문의 |
| 로그인 페이지가 안 열림 / 계속 로딩? | 회사 내부망 (WiFi/유선) 연결 확인, 주소는 `http://IP` 사용 (localhost 아님) |
| 통합 계정 비밀번호 분실? | 관리자에게 재설정 요청 (또는 도메인 계정으로 복구) |
### 7.2 사용
| 질문 | 해결 |
| --- | --- |
| 할당량 부족 안내? | NewAPI 백오피스에서 잔액 확인; 소진 시 관리자에게 충전/증액 요청 |
| 전송 내용이 차단됨? | 민감어 또는 민감 정보에 해당, 제6장 규정에 따라 조정 후 재시도 |
| DeepChat 연결 타임아웃? | 설정 → 네트워크/프록시 → 「프록시 사용 안 함/직접 연결」로 변경 |
| 모델 응답 품질이 낮음? | 다른 모델로 변경, 또는 질문 최적화 (맥락 제공, 요구 명확히, 예시 제공) |
| DeepChat 다운로드 위치를 잊음? | 포털 다운로드 센터 `http://IP:8090/downloads/` |
| Dify 앱 생성 시 계속 로딩? | 보통 네트워크/WebSocket 문제, 관리자에게 문의; 브라우저 Ctrl+F5 강력 새로고침 |
### 7.3 인식
| 질문 | 해결 |
| --- | --- |
| AI 답변을 믿어도 되나요? | 전부 믿으면 안 됩니다. AI는 틀릴 수 있고(환각), 중요한 사실, 숫자, 코드는 반드시 사람이 검증 |
| AI가 내가 한 말을 기억하나요? | 현재 대화 맥락은 다중 턴 응답을 위해 보존되므로 기밀 정보를 입력하지 마세요 (제6장 참조) |

## 8. 행동 수칙

### 8.1 사용 규범
- 불법·위법 용도로 사용하지 않으며, 불법, 유해, 권리 침해 콘텐츠를 생성하지 않습니다;
- 플랫폼 보안 제한을 우회하지 않고, 할당량을 대량으로 소진하지 않습니다;
- AI 생성 콘텐츠를 대외 전송 시 사실을 검증하고 회사 정보 게시 규정을 준수합니다;
- 본인의 API Key를 잘 보관하고, 타인에게 빌려주지 않으며, 코드 저장소에 커밋하지 않습니다;
- 이상 발견 시 (계정 이상, 콘텐츠 이상) 관리자에게 즉시 보고합니다.
### 8.2 한 문장 요약
> ✅ AI를 잘 활용해 효율을 높이되, **기밀은 보내지 않고, 사실은 반드시 검증하고, 규칙은 지킵니다**. 문제가 있으면 플랫폼 관리자에게 문의하세요.
