## 第四部分 简答/场景题（10 题，每题 2 分）

91. 【M03】简述 SSO 授权码流程（用户点登录 → 产品重定向 → Keycloak 认证 → 回跳换 token → 登录成功）。答出 4 步得全分。
92. 【M04】为什么 NewAPI 渠道 Base URL 用 litellm:4000 而不是 localhost？答：同一 ai-platform 网络，容器名即主机名；localhost 指向容器自身。
93. 【M05】guardrails 不生效的可能原因与修复？答：缺 default_on: true；Presidio 环境变量带 /analyze（只填 base URL）。
94. 【M06】知识库搜不到内容的排查顺序？答：embedding 模型是否默认 → 索引是否完成 → 检索参数 → 文档内容/分段。
95. 【M07】Ghost 管理员登录流程？答：输入邮箱 → 验证码邮件到 MailHog :8025 → 输入验证码；或 AI 管理中心免登录（TOTP 本地计算）。
96. 【M08】Runner job 跑不起来怎么排查？答：docker logs gitea-runner → force_pull 镜像拉取 → container.network → docker.sock 重复挂载。
97. 【M09】员工 DSH Desktop 连不上的排查？答：API Base URL（内网 IP + /v1）→ NewAPI 可达性 → token 有效性/额度 → 模型名。
98. 【M10】RAG 检索 404/无结果的排查？答：DIFY_API_BASE 是否带 /v1 → dataset_id/key 是否正确 → 网络（内网 IP 访问 Dify）→ 中文编码。
99. 【M11】管理员授权被撤销但产品侧仍可用，怎么处理？答：撤销流程包含产品侧删账号（SSO 撤销授权/API 删账号）；检查 provision 是否执行成功。
100. 【M17】AI 运维中"验证不轻信"如何落实？答：要求 Agent 用命令证明（HTTP 状态码、日志行、ls 输出），尤其是"已修复"结论。
