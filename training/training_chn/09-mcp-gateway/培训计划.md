## 2. 上机练习清单

- [ ] curl 验证 /health 与 tools/list（内置 4 工具可见）（S 关键项）
- [ ] DSH Desktop 中调用 platform_time / platform_services
- [ ] 在 mcp-servers.json 添加一个外部 MCP Server（stdio 或 http），重启后工具带前缀可见（S 关键项）
- [ ] 在 gateway.js 添加自定义工具 platform_health 并验证
- [ ] 在 skills/ 放一个技能（或上传 zip），/skills 清单可见，从 URL 安装成功（S 关键项）
- [ ] .env 配置 DIFY_API_BASE / DIFY_KNOWLEDGE_API_KEY / DIFY_DEFAULT_DATASET_ID，重启 mcp-gateway
- [ ] DSH Desktop 调用 search_knowledge 检索到知识库内容（S 关键项）
- [ ] 用 X-Admin-Token 调 /api/servers 增删一个 Server

## 3. 课后作业
1. 画出「DSH Desktop → MCP Gateway → Dify 知识库」RAG 链路图，标注 3 个坑。
2. 阅读 `ch20-ops-mcp.md`，总结 5 条运维要点。
3. 为一个内部 API 写一个 MCP Server 接入方案（stdio 或 http）。

## 4. 常见错误演练
- DIFY_API_BASE 只写 `http://<IP>`（缺 /v1）→ 检索 404/308。
- 中文 query 用 curl -d 直传 → 400（用文件/脚本）。
- 外部 MCP Server 起不来 → 看 gateway.js 日志。
