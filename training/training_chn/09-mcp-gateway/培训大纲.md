# MCP Gateway 培训大纲（M10 · 工具与技能网关）

## 1. 课程定位
MCP Gateway 是平台的 **Skill / MCP 工具集中管理网关**：DeepChat 和 Dify 连一个地址即可使用所有工具（内置平台工具 + 聚合的外部 MCP Server + Dify 知识库检索 RAG），同时托管内网 **Skill 市场**。它是平台「AI 能力扩展」的核心枢纽。

## 2. 教学目标
学完本模块，学员应能：
1. 解释 MCP 协议基本概念（Host/Client/Server、Streamable HTTP、SSE）与平台内角色。
2. 说明内置平台工具（platform_time / platform_echo / platform_services / search_knowledge）。
3. 独立配置外部 MCP Server 聚合（mcp-servers.json，stdio/http）与自定义内置工具。
4. 独立配置 Skill 市场（skills/ 目录、/market、/skills/<name>.zip）与技能管家。
5. 独立打通 **RAG 统一知识库检索**（Dify 侧准备 + .env 三项 + search_knowledge 验证）。
6. 使用管理 API（X-Admin-Token）与 AI 管理中心 MCP 页面做增删改。

## 3. 先修要求
- 完成 M06（Dify 知识库 + Knowledge API Key）、M09（DeepChat MCP 接入）。

## 4. 课程内容与学时（共 3 学时，D7 下午）

| 节 | 内容 | 学时 | 类型 |
|---|---|---|---|
| 1 | MCP 协议概述 + Gateway 架构（端口 3100、Streamable HTTP /mcp、SSE /sse） | 0.5 | 讲授 |
| 2 | 内置工具 + 验证（curl /health、/mcp tools/list） | 0.5 | 实操 |
| 3 | 聚合外部 MCP Server + 自定义内置工具 | 0.5 | 实操 |
| 4 | Skill 市场（/market、/skills、技能管家） | 0.5 | 实操 |
| 5 | RAG 统一知识库检索（search_knowledge 全链路 + 三个坑） | 0.75 | 讲授+实操 |
| 6 | 管理 API + AI 管理中心 MCP 页 + 排错 | 0.25 | 讲授 |

## 5. 达标标准（A 级）
- 独立完成「DeepChat 连 :3100/mcp → 调用 search_knowledge 检索到知识库内容」。
- 能上传/删除一个 Skill、增删一个外部 MCP Server。
- 能解释 RAG 链路的 3 个坑（网络打通、Knowledge Key 账号级、/v1 308 与中文 query 编码）。
