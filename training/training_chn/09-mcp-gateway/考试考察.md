## 一、理论题（30 分）

### 单选（每题 3 分，共 18 分）
1. MCP Gateway 的客户端接入端点（手动配置）是（　）
   A. `/sse`　B. `/mcp`（Streamable HTTP）　C. `/market`　D. `/health`
2. 内置工具中用于 RAG 知识库检索的是（　）
   A. platform_time　B. platform_echo　C. platform_services　D. search_knowledge
3. 外部 MCP Server 聚合后，工具名会自动加（　）前缀
   A. `ext_`　B. `{serverName}_`　C. `mcp_`　D. 不加
4. search_knowledge 调用的 Dify 接口是（　）
   A. `POST /v1/chat-messages`　B. `POST /v1/datasets/{id}/hit-testing`　C. `GET /v1/models`　D. `POST /v1/embeddings`
5. RAG 链路中 MCP Gateway 访问 Dify 应使用（　）
   A. 容器名 dify　B. 宿主机内网 IP `http://<服务器IP>/v1`　C. localhost　D. host.docker.internal:80
6. Skill 市场的技能包下载端点是（　）
   A. `/skills/<名称>.zip`　B. `/download`　C. `/market/<名称>.zip`　D. `/packages`

### 判断（每题 3 分，共 12 分）
7. MCP Gateway 的 /market 页面是只读的，增删改通过管理 API 或文件。（　）
8. 修改 mcp-servers.json 后需要重启 mcp-gateway 容器。（　）
9. 技能放在 skills/ 目录后需要重启才能被扫描到。（　）→ 错，每次请求自动扫描。
10. DeepChat 内置 difyKnowledge 方案比网关 search_knowledge 更适合企业统一管控。（　）→ 错，密钥散落客户端，网关更优。
