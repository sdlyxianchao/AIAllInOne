# Gitea + Runner 培训大纲（M08 · 源码与 CI/CD）

## 1. 课程定位
Gitea 是平台的内网 **Git 代码托管 + CI/CD（Actions）** 系统：承载 DeepChat 源码镜像、`deepchat-sync` 自动同步工作流、发布自动化。开发团队用它做源码管理与构建流水线。

## 2. 教学目标
学完本模块，学员应能：
1. 解释 Gitea 在平台中的角色（端口 3002、SSH 2222、Runner、Actions）。
2. 独立完成 Gitea 初始化、启用 Actions、创建 Runner 并注册。
3. 理解并排查 `deepchat-sync` 工作流（schedule + workflow_dispatch、sync-config.json、update_ghost.py）。
4. 配置 Gitea 与 Keycloak SSO（自动注册、邮箱一致）。
5. 编写简单 Gitea Actions 工作流（.gitea/workflows/*.yml）。
6. 处理常见问题（readonly database、ROOT_URL、runner 注册失败、force_pull 问题）。

## 3. 先修要求
- 完成 M02（核心服务启动）、M03（Keycloak，可选 SSO 部分）。

## 4. 课程内容与学时（共 3 学时，D6 下午）

| 节 | 内容 | 学时 | 类型 |
|---|---|---|---|
| 1 | Gitea 概述：端口 3002/SSH 2222、Runner、Actions 兼容 GitHub Actions | 0.5 | 讲授 |
| 2 | 初始化 + 启用 Actions + 创建 Runner + 注册 Token | 0.75 | 实操 |
| 3 | deepchat-sync 工作流拆解（sync-config.json 三个开关、version_cmp、update_ghost.py） | 0.75 | 讲授+实操 |
| 4 | Gitea Actions 语法（on/jobs/steps/容器）与简单示例 | 0.5 | 实操 |
| 5 | Keycloak SSO 自动注册 + 常见问题 | 0.5 | 讲授 |

## 5. 达标标准（A 级）
- 独立完成 Gitea 初始化 → Runner 注册（状态 Idle）→ 手动触发 deepchat-sync → 查看运行日志。
- 能写一个简单的 push 触发工作流。
- 能解释 Runner 的 4 个关键坑（container.network、docker.sock、force_pull、GitHub 网络）。
