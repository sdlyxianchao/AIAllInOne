## 2. 上机练习清单

- [ ] Gitea 初始化完成，管理员账号统一（S 关键项）
- [ ] ROOT_URL 已设为内网地址，仓库链接正确
- [ ] Actions 已启用，Runner 创建并注册成功（状态 Idle）（S 关键项）
- [ ] 手动触发 dsh-sync 工作流，日志正常、version.txt 有记录
- [ ] 在 dsh-sync 仓库查看 sync-config.json 三项配置含义
- [ ] 新建仓库 test-ci，写 .gitea/workflows/demo.yml（push 触发），运行成功（S 关键项）
- [ ] 配置 Keycloak SSO 登录 Gitea（可选，若已配 AD）

## 3. 课后作业
1. 编写一个「release 触发 → 构建 → 上传 Update Server」的工作流骨架。
2. 阅读 `ch19-ops-gitea.md`，总结 5 条运维要点。
3. 解释 dsh-sync 为什么"只有新版才下载"（防止回退）。

## 4. 常见错误演练
- 用 restart 而非 up -d 更新 token → Runner 不认新 token。
- force_pull 未关 → job 镜像拉取失败。
- ROOT_URL 是 localhost → 链接错误。
