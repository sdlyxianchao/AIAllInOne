# DSH Desktop 培训大纲（M09 · 桌面 AI 客户端）

## 1. 课程定位
DSH Desktop 是平台的**本地 AI 桌面客户端**（Windows/macOS/Linux）：员工电脑上安装，通过 NewAPI 统一调用大模型，支持 MCP 工具、Skill 技能包、本地文件读写。是员工日常使用最频繁的 AI 工具，也是答疑高频产品。

## 2. 教学目标
学完本模块，学员应能：
1. 解释 DSH Desktop 在平台中的角色（客户端 → NewAPI:3000/v1 → LiteLLM → 外部模型）。
2. 独立安装 DSH Desktop 并配置模型服务（API Base URL、API Key、模型选择）。
3. 配置 MCP Server（手动配置 Streamable HTTP → `http://<服务器IP>:3100/mcp`；filesystem 本地工具）。
4. 安装 Skill 技能包（URL 安装、技能管家 skill-market）。
5. 理解自动更新链路（Update Server → version.txt → 自动下载安装）与分发方式。
6. 解决常见问题（连接失败、找不到手动配置、IP 被脱敏、SSE 提示）。

## 3. 先修要求
- 完成 M04（dsh-key）；了解 MCP 基本概念（或与 M10 联学）。

## 4. 课程内容与学时（共 3 学时，D7 上午）

| 节 | 内容 | 学时 | 类型 |
|---|---|---|---|
| 1 | DSH Desktop 概述：功能、平台内角色、分发方式 | 0.5 | 讲授 |
| 2 | 安装 + 配置模型服务 + 测试对话 | 0.75 | 实操 |
| 3 | MCP 接入（一键接入 /sse 与手动 /mcp 的区别）+ filesystem 工具 | 0.75 | 实操 |
| 4 | Skill 安装（URL + 技能管家）+ 自动更新链路 | 0.5 | 实操 |
| 5 | 常见问题与排错 | 0.5 | 讲授 |

## 5. 达标标准（A 级）
- 独立安装并配置 DSH Desktop 成功对话。
- 能指导员工：怎么装、怎么配模型、怎么连 MCP、怎么装技能。
- 理解自动更新链路与三种分发方式。
