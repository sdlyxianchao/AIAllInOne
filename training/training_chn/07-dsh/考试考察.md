## 一、理论题（30 分）

### 单选（每题 3 分，共 18 分）
1. 员工电脑上 DSH Desktop 的 API Base URL 应填（　）
   A. `http://localhost:3000/v1`　B. `http://<服务器IP>:3000/v1`　C. `http://litellm:4000/v1`　D. `http://<服务器IP>:3100/mcp`
2. DSH Desktop 新增 MCP 服务器时，要出现「可流式传输的 HTTP 请求」类型，必须先（　）
   A. 选模板　B. 点「跳过至手动配置」　C. 输入命令　D. 重启
3. MCP 与 Skill 的关系是（　）
   A. 同一个概念　B. MCP 是工具（function calling），Skill 是智能体技能包（SKILL.md+脚本）
   C. Skill 是 MCP 的子集　D. 无关
4. 技能管家 skill-market 的 market_url 为什么必须用主机名（　）
   A. 主机名更短　B. DSH Desktop 会把 IP 脱敏成 [IP_ADDRESS_REDACTED]
   C. IP 访问更慢　D. 无要求
5. DSH Desktop 自动更新检查的版本信息文件是（　）
   A. version.txt　B. latest.yml　C. package.json　D. config.json
6. 通过 `dsh://mcp/install` 一键接入走的是（　）端点
   A. /mcp（Streamable HTTP）　B. /sse（SSE）　C. /market　D. /skills
