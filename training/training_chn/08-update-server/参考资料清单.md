## 三、学习说明

Update Server 本质是 **nginx 静态文件托管**，无独立官方教程。核心知识 = 静态服务 + electron-builder 自动更新机制。建议学习顺序：
1. 读《教材.md》→ 理解分发链路与 version.txt/latest.yml/publish.url 三者关系；
2. 实操：上传安装包 → curl -I 验证 → 检查 latest.yml 格式；
3. 深入：electron-builder publish 配置文档（Generic provider）；
4. 关联：dsh-sync 工作流（M08）与 Ghost 下载页（M07）构成完整分发闭环。
