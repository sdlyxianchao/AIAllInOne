# Update Server 培训大纲（M12 · 安装包分发）

## 1. 课程定位
Update Server 是 DSH Desktop 安装包的**内网托管与自动更新服务**（端口 8091，nginx）：员工从这里下载安装包，DSH Desktop 客户端从这里自动更新。

## 2. 教学目标
1. 解释 Update Server 在分发链路中的位置（GitHub → Gitea Actions → Update Server → Ghost 下载页 → 员工/客户端）。
2. 能上传安装包（.exe/.dmg/latest.yml）并验证下载链接。
3. 理解 DSH Desktop 自动更新机制（version.txt / latest.yml / publish.url）。
4. 会处理常见问题（403 空目录、latest.yml 缺失、版本回退）。

## 3. 先修要求
M07（Ghost 下载页）、M08（dsh-sync）。

## 4. 课程内容（共 1 学时，D8 下午）
| 节 | 内容 |
|---|---|
| 1 | 角色与链路 + 目录结构（dsh-updates/dsh/） |
| 2 | 手工上传安装包 + 验证（curl -I 200/206） |
| 3 | 自动同步（dsh-sync）+ 下载页联动 |
| 4 | 常见问题 |

## 5. 达标标准
- 能上传一个新版本安装包并让 Ghost 下载页出现新链接。
- 能解释「version_source」「download_prefix」「keep_releases」对分发的影响。
