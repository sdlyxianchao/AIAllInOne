# 培训配套制度与 FAQ（其他培训相关内容）

> 本文件汇总培训组织所需的配套内容：管理制度、环境准备清单、常见问题、结业后跟踪。

## 一、培训管理制度（建议）

### 1. 考勤与学分
- 每学时记 1 学分，共 60 学分；出勤率 <80% 不安排结业考核。
- 迟到/早退 3 次记 1 次缺勤；事假需提前 1 天报备。

### 2. 作业与阶段测验
- 每日作业次日开课前提交；未交 1 次扣平时分 5 分。
- 阶段测验（D2/D5/D8 末）成绩计入平时分（占比 10%，由讲师掌握）。

### 3. 上机纪律
- 训练机独立操作；禁止在训练机使用真实企业数据/密钥。
- 遇到故障先自查 15 分钟（日志优先），再求助；求助时能说清"现象 + 已尝试"。

### 4. 结业与证书
- 三项考核达标 → 结业证书（模板见 `17-考试考察/考核评分表.md` 附页）。
- 证书编号：AIAIO-期次-序号；成绩归档 `17-考试考察/成绩/`。

## 二、培训环境准备清单（讲师用）

- [ ] 训练机：Windows 11 Pro + Docker Desktop（WSL2），内存 ≥16GB、磁盘 ≥60GB SSD
- [ ] Docker Desktop 已启动，`docker info` 正常
- [ ] 平台代码已就位：`C:\AIAllInOne`（含 windows/、docs/、trainning/）
- [ ] `.env` 已配置（🔴 必填 8 项），DeepSeek API Key 配额充足
- [ ] `ai-platform` 网络已创建；内网 IP 已固定（DHCP 保留）
- [ ] 可选：Hyper-V 域控 VM（AD 集成演示）、Ollama（bge-m3）
- [ ] 培训资料打印：端口速查卡、账号清单（脱敏版）、每日作业单
- [ ] 阶段测验试卷与机考环境（D2/D5/D8）
- [ ] 结业考核：理论试卷 A/B 卷、实操评分表、答辩题库

## 三、培训 FAQ

### 1. 我没有技术背景，能学吗？
本培训面向有基本 IT 操作能力的学员。M01/M02 会从零讲起；核心模块均为"跟着做"型实操。建议 C 级（支持岗）先学，掌握后转 A 级深造。

### 2. 培训一定要真实部署吗？
是的。本培训以"真实部署一台平台"为主线（约 41 个容器），不部署不结业。一台训练机即可完成全部练习。

### 3. 没有 AD 域控怎么练 Keycloak？
方式 A（本地账号）可完成 80% 练习；AD 部分可用讲师准备的 Hyper-V 域控 VM，或按文档用 OpenLDAP 模拟。

### 4. 外部大模型 API Key 怎么准备？
DeepSeek（platform.deepseek.com）注册即可，成本低；至少 1 个 Key 用于打通 LLM 链路。也可用 OpenAI/Claude。

### 5. 培训完就能上岗吗？
达到 A 级标准（部署/配置/运维/答疑/安全五项达标）即可独立承接平台部署与运维；建议结业后跟岗实习 1 周（在真实环境做巡检与答疑）。

### 6. 平台版本升级了怎么办？
培训教材基于 v0.9x（Windows 版）。升级后以 `windows-deploy-guide-v2.md` 与 `docs/` 手册为准；关注 GitHub Releases 与更新日志。

### 7. 后续要生成培训手册 PDF？
本套材料为 Markdown + HTML，可直接打印/转换：
- 单文件转 PDF：Typora / VS Code + Markdown PDF 插件 / Pandoc；
- 整套手册：由 `index.html`（已含打印样式）Ctrl+P 另存 PDF，或按目录逐章合成。

### 8. 内网怎么访问视频教程？
视频索引（`99-参考资料/视频教程索引.md`）均为公网链接。需要内网化时，可提前下载视频放内网共享或门户（注意版权），并更新索引中的链接。

## 四、结业后跟踪（建议）
| 周期 | 动作 |
|---|---|
| 第 1 周 | 跟岗实习：每日巡检 + 真实答疑，输出巡检报告 |
| 第 1 个月 | 独立完成一次备份恢复演练；一次新员工答疑 |
| 每季度 | 平台升级后复训新特性；参加社区交流（微信群/GitHub Discussions） |
