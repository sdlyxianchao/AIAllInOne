# Dify 培训大纲（M06 · AI 应用平台）

## 1. 课程定位
Dify 是平台的 **Web AI 应用平台**：员工通过浏览器使用 AI（聊天助手、Agent、工作流、文本生成），管理员在此配置模型供应商、搭建**统一知识库（RAG）**、管理成员权限。Dify 是平台**面向全体员工**的核心产品，也是培训答疑的高频对象。

## 2. 教学目标
学完本模块，学员应能：
1. 解释 Dify 在平台中的位置（独立部署 15 容器、端口 80、通过 NewAPI 调模型）。
2. 独立完成 Dify 部署排错（GRAPH_ENGINE 修复、WebSocket 地址、base64 登录密码、密码重置）。
3. 配置模型供应商（OpenAI-API-compatible → `http://host.docker.internal:3000/v1`）与 embedding 模型。
4. 创建聊天助手、文本生成、Agent、工作流四类应用，并发布/嵌入。
5. 创建知识库（高质量索引、分段、检索参数）并做 RAG 应用；生成 Knowledge API Key。
6. 管理成员与权限、查看使用统计，回答员工常见问题。
7. 了解 Dify 与 MCP Gateway 的集成（M10 详述）。

## 3. 先修要求
- 完成 M02（Dify 独立部署）、M04（NewAPI 的 dify-key）。

## 4. 课程内容与学时（共 6 学时，D5）

| 节 | 内容 | 学时 | 类型 |
|---|---|---|---|
| 1 | Dify 概述：五类应用、独立部署架构、平台内角色 | 0.5 | 讲授 |
| 2 | 部署排错专题：GRAPH_ENGINE_SCALE_UP_THRESHOLD、NEXT_PUBLIC_SOCKET_URL、base64 密码、reset-password | 0.5 | 讲授+实操 |
| 3 | 模型供应商配置（LLM + embedding）+ 创建第一个聊天助手 | 1.0 | 实操 |
| 4 | 知识库 RAG：创建知识库/分段/检索参数 + 知识库应用 + Knowledge API Key | 1.5 | 讲授+实操 |
| 5 | Agent 与工作流：Agent 工具编排、Workflow 节点（知识检索/HTTP/条件） | 1.0 | 实操 |
| 6 | 发布/嵌入网站 + 成员权限 + 使用统计 + 常见问题 | 0.5 | 讲授 |
| 7 | 综合练习：搭建一个「基于知识库的智能客服」并发布 | 1.0 | 实操 |

## 5. 达标标准（A 级）
- 独立完成「模型供应商 → 知识库 → RAG 聊天助手 → 发布」全流程。
- 能回答员工：怎么建应用、为什么知识库搜不到、怎么申请 API。
- 能处理部署级故障（WebSocket 连不上、忘记密码重置、容器 Restarting）。
