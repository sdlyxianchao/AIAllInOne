## 2. 上机练习清单

- [ ] 配置模型供应商（deepseek-chat 经 host.docker.internal:3000/v1 + bge-m3 embedding 设默认）并测试成功（S 关键项）
- [ ] 创建聊天助手应用，对话收到回复
- [ ] 创建知识库（High quality），上传 ≥2 份文档，索引完成
- [ ] 创建知识库应用（Chatflow + 知识检索），检索命中（S 关键项）
- [ ] 创建 Knowledge API Key，记录 key 与 dataset_id
- [ ] 创建 Agent 应用并配置至少 1 个工具
- [ ] 创建 Workflow 应用（含知识检索节点）
- [ ] 发布一个应用并获取 WebApp 链接 / 嵌入代码
- [ ] 用 curl 调 Service API 完成一次对话（可选加分）

## 3. 课后作业
1. 整理一份「Dify 常见问题速查卡」（10 条以上，含解决步骤）。
2. 阅读 `../../Dify-RAG-接入实现方案.md`，画出 RAG 检索链路图（DeepChat → MCP → Dify Knowledge API）。
3. 在 Dify 中为知识库调整检索参数（top_k / score_threshold），记录效果差异。

## 4. 常见错误演练
- 模型供应商 API endpoint 写错（少了 /v1）→ 测试失败。
- embedding 未设默认 → 创建知识库报错。
- WebSocket 地址为 localhost → 工作流调试卡住。
- Knowledge API Key 用错账号/数据集 → search_knowledge 无结果。

## 5. 阶段衔接
- Knowledge API Key 与 .env 配置是 M10（MCP Gateway search_knowledge）的前置。
- 发布应用到 Ghost 门户是 M07（Ghost）的实操内容。
