# NewAPI 考试考察（M04）

> 理论 10 题（30 分）+ 实操 3 项（50 分）+ 答辩 3 问（20 分），≥70 通过。

## 一、理论题（30 分）

### 单选（每题 3 分，共 18 分）
1. 本平台中 NewAPI 的 LLM 渠道 Base URL 应填（　）
   A. `http://localhost:4000`　B. `http://litellm:4000`　C. `http://<服务器IP>:4000`　D. `http://newapi:4000`
2. 渠道密钥应填（　）
   A. DeepSeek API Key　B. `LITELLM_MASTER_KEY` 的实际值　C. 任意字符串　D. Keycloak Client Secret
3. NewAPI 首次初始化建议选择的使用模式是（　）
   A. 对外运营　B. 演示站点　C. 个人使用　D. 都行
4. OIDC 接入中，令牌端点和用户信息端点必须改为（　）供容器内部访问
   A. `127.0.0.1:9090`　B. `<服务器IP>:9090`　C. `host.docker.internal:9090`　D. `keycloak:9090`
5. SSO 用户登录后访问管理页 403，原因是（　）
   A. 限流　B. 用户 role 太低（common），需提权 role=100　C. 渠道没配　D. 密码错
6. 员工新用户额度为 0 无法调用模型，正确做法是（　）
   A. 重启容器　B. 在 .env 设 DEFAULT_QUOTA 后**只对未注册过的新用户**生效，老用户在后台手动调整额度
   C. 删除重建用户　D. 改渠道

### 判断（每题 3 分，共 12 分）
7. dify-key 与 dsh-key 分开创建便于分别统计用量。（　）
8. 授权端点也应改成 host.docker.internal。（　）→ 错，授权端点是浏览器跳转，保持内网地址。
9. 设置服务器地址为内网 IP 后，本机调试也应改用内网 IP 访问。（　）
10. NewAPI 的限流变量（CRITICAL_RATE_LIMIT 等）在系统设置页而非 .env 配置。（　）→ 错，在 .env。
