# NewAPI 培训大纲（M04 · LLM 路由网关）

## 1. 课程定位
NewAPI 是平台的 **LLM 路由与 API 网关**：所有 AI 应用（Dify、DSH Desktop）都通过它统一调用外部大模型，实现**渠道管理、API 密钥（令牌）管理、额度/计费、限流、日志审计**。它是平台「LLM 全链路」的第一站。

## 2. 教学目标
学完本模块，学员应能：
1. 解释 NewAPI 在平台中的位置与数据流（DSH Desktop/Dify → NewAPI → LiteLLM → 外部模型）。
2. 独立完成首次初始化向导（数据库检查、管理员、使用模式）。
3. 独立配置 LLM 渠道（指向 LiteLLM）、测试连通性、创建 API 密钥。
4. 配置 Keycloak OIDC 登录（含 host.docker.internal 端点修正、服务器地址设置、管理员提权）。
5. 管理用户额度（默认额度、手动调整）、分组与模型权限、限流参数。
6. 查看仪表盘、使用日志、成本报表、审计日志，回答用户关于用量的问题。
7. 排查常见故障（渠道测试失败、429 限流、OIDC 403、token 无效）。

## 3. 先修要求
- 完成 M02（Docker 部署核心服务）与 M03（Keycloak）。
- 掌握 OpenAI API 基本格式（base_url、Authorization、chat/completions）。

## 4. 课程内容与学时（共 3 学时，D4 上午）

| 节 | 内容 | 学时 | 类型 |
|---|---|---|---|
| 1 | NewAPI 概述：端口 3000、与 OneAPI 的关系、平台内角色、使用模式区别（个人/对外运营/演示） | 0.5 | 讲授 |
| 2 | 首次初始化向导 + 管理员账号约定 | 0.5 | 实操 |
| 3 | 渠道配置（OpenAI 类型 → LiteLLM:4000）+ 测试 + 模型获取 | 0.5 | 实操 |
| 4 | API 密钥管理（dify-key / dsh-key 分开）+ 用户自助申请（DEFAULT_QUOTA / GENERATE_DEFAULT_TOKEN） | 0.5 | 实操 |
| 5 | Keycloak OIDC 接入（Client、自动发现、host.docker.internal 修正、服务器地址、提权） | 0.5 | 实操 |
| 6 | 用量/成本/审计 + 分组配额 + 限流参数 + 排错 | 0.5 | 讲授+实操 |

## 5. 达标标准（A 级）
- 独立完成 NewAPI 初始化 → 渠道 → 密钥 → OIDC 全流程。
- 能口述「为什么渠道 Base URL 填 `http://litellm:4000` 而非 localhost」「为什么 OIDC 令牌端点要改 host.docker.internal」。
- 能看懂仪表盘与使用日志，能回答员工「我怎么申请 API Key / 额度为什么是 0」。
