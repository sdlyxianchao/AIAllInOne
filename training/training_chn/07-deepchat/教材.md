# DeepChat 教材（M09 · 桌面 AI 客户端）

> DeepChat 是**桌面应用**，不在 Docker 里。员工电脑安装，API 指向 `http://<服务器IP>:3000/v1`（NewAPI）。

## 1. DeepChat 是什么

DeepChat 是开源桌面 AI 对话客户端（Electron），支持 30+ 模型提供商、MCP 工具、Skill 技能包、多窗口多标签、Markdown 渲染、本地文件读写。本平台中它是员工使用 AI 的**主力客户端**：

```
员工电脑 DeepChat ──HTTP──> NewAPI(:3000/v1) ──> LiteLLM ──> 外部大模型
                                └── MCP ──> MCP Gateway(:3100/mcp) ──> 工具/Skill/知识库
```

## 2. 三种分发方式

| 方式 | 说明 |
|---|---|
| **A. 内网分发（推荐）** | GitHub Release 安装包 → `deepchat-sync` 工作流 → Update Server(:8091) → Ghost 下载页 → 员工下载；DeepChat 自动更新检查 `version.txt` |
| B. Docker 构建自定义版 | 临时容器 `node:20` 跑 `electron-builder`，产物（.exe + latest.yml）放 deepchat-updates |
| C. 直接给安装包 | 拷贝 .exe 分发给员工 |

## 3. 安装与配置

### 3.1 安装
- 从门户下载中心 `http://<服务器IP>:8090/deepchat/`（或 Update Server `:8091`）下载对应平台安装包安装。

### 3.2 配置模型服务
1. 打开 DeepChat → **设置** → **模型服务**。
2. 选择「自定义 Provider」或「OpenAI 兼容」：
   - **API Base URL**：`http://<服务器IP>:3000/v1`（员工电脑上必须内网 IP）
   - **API Key**：`deepchat-key` 的 sk-xxx（或员工自己在 NewAPI 申请的 token）
   - **模型**：`deepseek-chat` / `gpt-4o-mini`（看渠道配了哪些）
3. 保存 → 新对话 → 发"你好" → 收到回复。

## 4. MCP 接入（重点）

### 4.1 手动配置（推荐，Streamable HTTP）
1. DeepChat → **设置** → **MCP** → **新增** → **「跳过至手动配置」**（⚠️ 必须点，否则进模板选择页找不到手动界面）。
2. 类型选 **可流式传输的 HTTP 请求（HTTP）**。
3. 基础 URL：`http://<服务器IP>:3100/mcp`。
4. 保存后对话中可调用平台工具（platform_time / search_knowledge 等）。

### 4.2 一键接入（SSE，了解）
- 通过 `/market` 页或 AI 管理中心复制 `deepchat://mcp/install` 链接，走 **SSE 端点 `/sse`**。
- DeepChat 的 deepchat:// 处理器只接受 stdio/sse；SSE 显示「SSE is legacy-only」提示属**正常**，不影响使用。
- 两者连同一网关、同一套工具。

### 4.3 filesystem 本地工具（示例）
- 添加 MCP Server：名称 `filesystem`，命令 `npx -y @modelcontextprotocol/server-filesystem C:\Users`。
- 对话中测试「列出我的文件」。

## 5. Skill 技能包安装

- **MCP vs Skill 是两个概念**：MCP = 工具（function calling）；Skill = 智能体技能包（SKILL.md 指令 + 脚本）。
- 安装方式（官方仅支持三种）：文件夹 / ZIP / **URL**。内网分发靠 URL：
  - DeepChat → 设置 → Skills → **从 URL 安装** → `http://<服务器IP>:3100/skills/<名称>.zip`
- **技能管家 skill-market**：员工先装它，之后对话里问「有哪些技能 / 帮我装 X / 更新技能」。
  - 它读 `config.json` 的 `market_url` → 请求 `/skills` 清单 → 筛选/推荐/给安装指引。
  - ⚠️ `market_url` 必须用**主机名**（如 `skillmarket.<公司域名>`），不能用 IP——DeepChat 会把 IP 脱敏成 `[IP_ADDRESS_REDACTED]` 导致读不到。

## 6. 自动更新链路

```
GitHub Releases ──> deepchat-sync (Gitea Actions，每日UTC 2点) ──> Update Server(:8091/deepchat/)
    └─ 更新 version.txt ──> DeepChat 客户端启动时检查 → 有新版本自动下载安装
```
- DeepChat 的 `publish.url` 指向 `http://<服务器IP>:8091/deepchat/`（generic provider，读 latest.yml）。
- 下载页由 update_ghost.py 自动维护（时间轴、keep_releases 裁剪、幂等）。

## 7. 常见问题

| 问题 | 解决 |
|---|---|
| 连接失败/无响应 | API Base URL 是否内网 IP + /v1；NewAPI 是否可达；token 是否有效/有额度 |
| 找不到「可流式传输的 HTTP」类型 | 新增后要点「跳过至手动配置」 |
| SSE 显示 legacy-only 提示 | 正常，不影响；或改手动配置走 /mcp |
| 技能管家读不到市场 | market_url 用了 IP（被脱敏），改主机名并在 hosts/DNS 解析 |
| 收不到自动更新 | version.txt 是否最新；Update Server 是否可达；latest.yml 是否正确 |
| 员工不知道从哪下载 | 门户 `/deepchat/` 下载页 |
