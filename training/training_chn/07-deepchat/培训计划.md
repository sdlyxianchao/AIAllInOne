| 时段 | 内容 | 方式 | 资料 |
|---|---|---|---|

| 09:30-10:15 | 实操 1：安装 + 配置模型服务 + 对话测试 | 上机 | 部署指南 7.3 节 |
| 10:15-11:00 | 实操 2：MCP 手动配置（/mcp）+ filesystem 工具 | 上机 | 教材 4 章 |

## 2. 上机练习清单

- [ ] 安装 DeepChat（可从 Update Server/门户下载）（S 关键项）
- [ ] 配置 OpenAI 兼容 Provider（内网 IP + /v1 + deepchat-key + deepseek-chat），对话成功（S 关键项）
- [ ] 手动配置 MCP（跳过至手动配置 → 可流式传输 HTTP → `http://<服务器IP>:3100/mcp`），tools/list 能看到平台工具（S 关键项）
- [ ] 调用一次 `platform_time` 或 `search_knowledge`（若已配 Dify 知识库）
- [ ] 从 URL 安装一个技能（如 platform-report）
- [ ] 配置技能管家 skill-market（理解 market_url 主机名要求）
- [ ] 验证自动更新：检查 version.txt 与最新版本一致

## 3. 课后作业
1. 写一份「DeepChat 员工使用指南」（安装/配模型/连 MCP/装技能/常见问题）。
2. 阅读 `ch10-deepchat.md`，总结分发链路各环节。
3. 在 DeepChat 中用 filesystem 工具完成一次本地文件操作。

## 4. 常见错误演练
- 不点「跳过至手动配置」→ 找不到 HTTP 类型。
- API Base URL 漏了 /v1 → 连接失败。
- market_url 用 IP → 技能管家读不到。

- MCP 接入依赖 M10（MCP Gateway）已运行。
- 自动更新链路涉及 M08（deepchat-sync）+ M12（Update Server）。
