# Ghost 培训计划（M07）

## 1. 课时安排（共 3 学时，D6 上午）

| 时段 | 内容 | 方式 | 资料 |
|---|---|---|---|
| 09:00-09:30 | Ghost 概述 + 平台内角色 + 免登录机制 | 讲授 | 教材 1~2 章 |
| 09:30-10:15 | 实操 1：初始化 + Corp Portal 主题激活 + 内容种子导入 | 上机 | 部署指南 6.5 节 |
| 10:15-11:00 | 实操 2：发布一篇公告文章 + 编辑导航 + 检查下载中心页 | 上机 | 教材 3.4 |
| 11:00-11:30 | 实操 3：创建 Admin API Key + MailHog 查看验证码 + AI 管理中心免登录体验 | 上机 | 教材 3.5/4 章 |
| 11:30-12:00 | 常见问题 + 排错演练 | 讲授 | 教材 5 章 |

## 2. 上机练习清单

- [ ] Ghost 初始化完成（用 ghost-setup.ps1 或向导）（S 关键项）
- [ ] Corp Portal 主题安装并激活（首页样式变化）（S 关键项）
- [ ] 内容种子导入成功（导航含 Home/DSH Desktop/Dify、下载页 /dsh/ 可访问）
- [ ] 发布一篇公告文章，前台可见
- [ ] 编辑导航（加一个自定义链接）
- [ ] 创建 Admin API Key 并记录
- [ ] 用 MailHog 查看一次验证码邮件
- [ ] 通过 AI 管理中心「打开 Ghost 后台」免登录进入

## 3. 课后作业
1. 在门户发一篇「AI 平台使用指引」文章（引用 Dify/NewAPI/DSH Desktop 地址）。
2. 阅读 `ch18-ops-ghost.md`，总结 5 条日常运营要点。
3. 画一张「员工从门户到达各产品」的导航链路图。

## 4. 常见错误演练
- 首页点注册 → 500（引导走 /ghost/）。
- 主题不兼容报错 → 换项目主题。
- 验证码收不到 → 检查 MailHog。

## 5. 阶段衔接
- 下载中心页引用的安装包由 M08（Gitea CI）与 M12（Update Server）维护。
- 门户嵌入 Dify 应用是 M06 的发布方式之一。
