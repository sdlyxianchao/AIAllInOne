# Ghost 培训大纲（M07 · 企业门户）

## 1. 课程定位
Ghost 是平台的**企业门户/新闻站**：发布公司公告、AI 平台使用指南、DeepChat 下载中心，聚合各产品入口（"AI All In One Hub"）。员工日常最先接触的就是门户首页。

## 2. 教学目标
学完本模块，学员应能：
1. 解释 Ghost 在平台中的角色（端口 8090、SQLite 数据库、Corp Portal 主题）。
2. 独立完成初始化（setup 向导 / ghost-setup.ps1）、安装激活主题、导入内容种子。
3. 独立发布文章/页面、管理导航、修改站点设置。
4. 配置邮件出口（MailHog）与理解 Ghost 免登录机制（AI 管理中心自动登录）。
5. 创建 Admin API Key（供 Gitea 发公告）。
6. 处理常见问题（/ghost/ 后台入口、members 注册 500、主题不兼容、验证码登录）。

## 3. 先修要求
- 完成 M02（核心服务启动）；了解 HTML 基础。

## 4. 课程内容与学时（共 3 学时，D6 上午）

| 节 | 内容 | 学时 | 类型 |
|---|---|---|---|
| 1 | Ghost 概述：端口 8090、`/ghost/` 后台、SQLite、平台内角色 | 0.5 | 讲授 |
| 2 | 初始化 + Corp Portal 主题 + 内容种子导入（含发布地址与语言选择） | 0.75 | 实操 |
| 3 | 内容管理：文章/页面/导航/标签/下载中心页 | 0.75 | 实操 |
| 4 | 邮件与登录：MailHog 验证码、AI 管理中心免登录、Admin API Key | 0.5 | 讲授+实操 |
| 5 | 常见问题与排错 | 0.5 | 讲授 |

## 5. 达标标准（A 级）
- 独立完成「初始化 → 主题 → 种子导入 → 发一篇文章」全流程。
- 能回答员工：门户怎么访问、文章怎么发、DeepChat 从哪下载。
- 理解 Ghost 5 免密登录机制与 MailHog 的作用。
