# Ghost 教材（M07 · 企业门户）

> 平台内 Ghost 端口 `8090`（容器 `ghost`），**SQLite 数据库**（`ghost-data` 卷），后台入口 `http://<服务器IP>:8090/ghost/`。

## 1. Ghost 是什么

Ghost 是基于 Node.js 的开源发布平台（博客/CMS）。本平台用它做**企业门户（AI All In One Hub）**：新闻公告、平台能力介绍、DSH Desktop 下载中心、各产品入口导航。自带定制主题 **Corp Portal**（稳重专业企业风、中文适配、移动端自适应）。

## 2. 平台内关键约定

| 约定 | 值 |
|---|---|
| 前台 | `http://<服务器IP>:8090` |
| 后台 | `http://<服务器IP>:8090/ghost/`（⚠️ 带 /ghost/ 后缀） |
| 管理员 | 统一账号 `ai_all_in_one_admin@<公司域名>`（密码 ≥10 位） |
| 数据库 | SQLite（`ghost.db`），compose 用环境变量强制覆盖（防旧 MySQL 残档） |
| 邮件出口 | MailHog（SMTP 1025，无认证）→ Web UI `:8025` 看验证码 |
| 登录方式 | Ghost 5 后台**免密**：输入邮箱 → 发 6 位验证码（TOTP）到 MailHog；或 AI 管理中心「打开 Ghost 后台」免登录 |

## 3. 标准操作流程

### 3.1 初始化
- **自动化（推荐）**：`powershell -File .\scripts\ghost-setup.ps1`（从 .env 读 GHOST_ADMIN_EMAIL/ADMIN_PASSWORD，走 setup API，已初始化自动跳过）。
- **手动**：访问 `:8090/ghost/` → setup 向导 → 站点标题/姓名/邮箱/密码。
- ⚠️ 别在门户首页 `/` 点「注册」——那是**订阅者（members）注册**，走 magic link 邮箱验证，未配 SMTP 会报 500。

### 3.2 安装激活 Corp Portal 主题
- **自动化（推荐）**：`powershell -File .\scripts\ghost-theme-setup.ps1`（复制主题进容器 → 改 `settings.active_theme` → 重启 Ghost）。
- 手工等价步骤：
  ```
  docker cp .\ghost-theme-corp-portal\. ghost:/var/lib/ghost/content/themes/corp-portal-theme/
  docker cp .\scripts\ghost-activate-theme.js ghost:/tmp/
  docker exec ghost node /tmp/ghost-activate-theme.js corp-portal-theme
  docker restart ghost
  ```
- ⚠️ 别从 GitHub 装最新主题：部分官方主题 main 分支已适配 Ghost 6.x，在 Ghost 5.x 上报「Theme is not compatible」（本项目主题已针对 5.x 验证）。

### 3.3 导入示例内容种子
```
powershell -File .\scripts\ghost-content-import.ps1 -ServerAddr "<对外发布地址>"
```
- 脚本做的事：复制 `ghost-content-seed/content.json` 进容器 → 替换 `<服务器IP>` 占位符（保留 host.docker.internal 不动）→ 创建文章/页面/导航/站点设置（幂等）。
- 语言：中文直接导入；其他语言先翻译 seed 的 title/html/plaintext/custom_excerpt 再导入。
- 导入后：首页为新闻列表，导航含 Home / DSH Desktop / Dify，下载页 `/dsh/` 有安装包链接。

### 3.4 内容管理
- 写文章：后台 → Posts → New → 编辑器（Markdown/卡片）→ Publish。
- 页面（Pages）：固定内容（关于/下载中心）。
- 导航：Settings → Navigation（管理菜单顺序与链接）。
- 下载中心：编辑 `/dsh/` 页面放安装包内网链接（`http://<服务器IP>:8091/dsh/...`）。

### 3.5 Admin API Key（供 Gitea 发公告）
后台 → **Integrations** → 添加自定义集成 → 生成 Admin API Key（格式 `id:secret`），供 Gitea Actions 工作流调用 `POST /ghost/api/admin/posts/` 发发布公告（见 M08）。

## 4. 邮件与免登录机制（理解即可，运维常用）

1. **Ghost 5 后台免密**：输入邮箱 → Ghost 发 6 位验证码邮件 → MailHog 接收（Web UI `:8025` 查看）。
2. **AI 管理中心免登录**（`/api/ghost/auto-login`）：后端自动完成「密码登录 → 读 `admin_session_secret` + userId 本地算 TOTP（HMAC-SHA1，6 位/60 秒）→ PUT /session/verify → 写 cookie → 跳转后台」，用户全程无感。
3. ⚠️ 即使自己算验证码，Ghost 仍会真的发邮件，**MailHog（或任意 SMTP）必须保留**，否则登录报 `Failed to send email`。

## 5. 常见问题

| 问题 | 解决 |
|---|---|
| 首页点「注册」报 500 | 那是 members 订阅注册，走 magic link；管理员用 `/ghost/` 入口 |
| ghost 容器一直 Restarting，连 MySQL 报错 | SQLite 环境变量覆盖（compose 已配）；不要删卷（会丢文章/主题） |
| 主题报 not compatible | 用项目自带 Corp Portal（已适配 Ghost 5.x），别装最新官方主题 |
| 收不到验证码 | 看 MailHog `:8025`；确认 mailhog 容器运行 |
| 登录报 Failed to send email | SMTP 出口不可用，检查 mail__* 环境变量与 mailhog 容器 |
| 想换回官方主题 | 后台 → 外观 → 主题 → 激活 Casper / Source |

## 6. 安全要点
- 后台入口 `/ghost/` 建议限制内网访问；管理员账号与平台统一约定。
- 门户发布内容遵循公司信息发布规范；下载中心只挂内网可信安装包。
