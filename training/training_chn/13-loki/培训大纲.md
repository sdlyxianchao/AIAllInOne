# Loki + Promtail 培训大纲（M15 · 统一日志）

## 1. 课程定位
Loki + Promtail 提供**容器统一日志聚合**：所有容器的应用日志汇聚到一处，AI 管理中心「统一日志」页按容器 + 关键字 + 时间范围查询。

## 2. 教学目标
1. 解释 Loki 设计哲学（只索引标签，不索引内容——比 ELK 轻量）与组件分工（Promtail 采集 → Loki 存储查询 → AI 管理中心查询）。
2. 熟练使用 AI 管理中心统一日志页（容器下拉、关键字、时间范围）。
3. 理解 promtail.yml 的 docker_sd 发现与标签（container/service/project），会改配置。
4. 了解 LogQL 基础（`{label="value"} |= "关键字"`）。

## 3. 先修要求
M02（容器启动）。

## 4. 课程内容（共 1 学时，D8 下午）
| 节 | 内容 |
|---|---|
| 1 | 架构（Loki 3110 / Promtail 内部 / 与 ELK 对比）+ Docker Desktop 挂载坑 |
| 2 | 实操：AI 管理中心统一日志查询（容器筛选 + 关键字 + 时间） |
| 3 | LogQL 基础 + promtail.yml 配置解读 |

## 5. 达标标准
- 能从统一日志中找到某容器某时段的报错日志。
- 能解释 Promtail 在 Docker Desktop 下的挂载路径要求（/var/lib/docker/containers，非 Windows 路径）。
