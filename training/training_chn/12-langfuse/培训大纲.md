# Langfuse 培训大纲（M14 · LLM 可观测）

## 1. 课程定位
Langfuse 是平台的 **LLM 可观测平台**（端口 3010）：追踪每一次模型调用的提示词、响应、模型、延迟、token、成本，出问题可回溯定位；还支持 Prompt 管理与评测。

## 2. 教学目标
1. 解释 Langfuse 数据来源（LiteLLM success_callback 自动上报）。
2. 熟练查看 trace 详情（prompt/response/latency/tokens/cost）、按项目/用户筛选。
3. 了解 Langfuse v4 组件（web/worker/postgres/clickhouse/minio/redis）与两个关键坑（V4_WRITE_MODE=dual、SSO 组织绑定）。
4. 会用 AI 管理中心「LLM 可观测」入口（IdP 发起式 SSO）。

## 3. 先修要求
M05（LiteLLM 上报配置）。

## 4. 课程内容（共 1.5 学时，D8 下午）
| 节 | 内容 |
|---|---|
| 1 | 架构与角色 + 数据流（LiteLLM → Langfuse） |
| 2 | 实操：登录 → 查看 trace 列表 → 打开一条完整 trace → 筛选某用户/模型 |
| 3 | 成本分析（按模型/日期）与质量分析入门 |
| 4 | 关键坑与排错 |

## 5. 达标标准
- 能从 Langfuse 找到"某次对话"的完整调用链并解读 token/成本。
- 能处理"看不到任何 trace"的两个原因（V4 写模式、SSO 组织绑定）。
