# AI Agent 运维 培训大纲（M17 · 智能运维）

## 1. 课程定位
本平台**设计为可通过 AI Agent 运维**（WorkBuddy / OpenClaw / Microsoft Scout）：不用逐个点管理后台，用自然语言让 Agent 读文件、跑命令、调 API 完成巡检/配置/排错。这是平台差异化能力，也是进阶运维技能。

## 2. 教学目标
1. 理解 Agent 运维的工作原理（代码/配置/数据皆在本地 + 命令 + API）。
2. 掌握常用运维提示词（健康检查、查故障、重启、日志、备份、发布）。
3. 会驱动 Agent 完成：全栈健康检查、故障定位与修复、dsh-sync 触发、Ghost 内容导入、备份恢复、版本发布。
4. 理解 best practices（前端/后端改动的重启区别、硬刷新、密钥不落地、验证不轻信）。
5. 掌握 quick command reference（docker ps/logs、compose up、Gitea API、backup.ps1、publish.ps1）。

## 3. 先修要求
完成 M01~M16（了解全部产品后，Agent 运维才有意义）。

## 4. 课程内容（共 3 学时，D9 下午）
| 节 | 内容 |
|---|---|
| 1 | 原理与准备（工作目录、Docker Desktop、凭据在 .env、平台目录选择） |
| 2 | 常用任务与提示词（4.1~4.10 逐条演示） |
| 3 | 实战：Agent 驱动一次完整健康检查 + 一次备份 + 一次故障演练 |
| 4 | Best practices 与排错 |

## 5. 达标标准
- 能用自然语言让 Agent 完成"检查所有服务健康并列出问题"并验证结果可信。
- 知道什么改动需要重启容器、什么只需刷新浏览器。
