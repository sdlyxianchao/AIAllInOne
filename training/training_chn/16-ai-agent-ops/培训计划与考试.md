## 考试考察

### 理论（每题 5 分，共 20 分）
1. AI 管理中心前端改动生效方式是（　）A. 重启容器 B. 刷新浏览器（Ctrl+F5）C. 重新部署 D. 重启 Docker
2. 后端 server.js 改动生效方式是（　）A. 刷新 B. docker restart admin-portal C. 无需操作 D. 改完即生效
3. health-check.ps1 的判定成功标志是（　）A. 无输出 B. 末尾 ALL CLEAR 且 Fail: 0 C. exit 0 即可 D. 日志非空
4. 运维提示词的基本原则不包括（　）A. 要求用命令证明结果 B. 破坏性操作先备份 C. 让 Agent 直接删除所有旧备份 D. 密钥留在 .env

### 实操（30 分）
1. 用 Agent 完成「健康检查 → 报告」并人工复核关键结论。（15 分）
2. 用 Agent 完成一次备份恢复演练（讲师监督）。（15 分）

### 答辩（1 问，10 分）
「你会如何向团队推广 AI 运维？哪些操作适合交给 Agent、哪些必须人工？」（巡检/备份/常规配置可交；生产变更/删除/敏感操作需人工确认）
