# AI 管理中心 培训大纲（M11 · 统一管理门户）

## 1. 课程定位
AI 管理中心（Admin Center）是平台**自研的统一管理员门户**（端口 10086）：Keycloak 鉴权、Dashboard 展示全部容器与业务指标、左侧菜单聚合所有产品、管理员分模块授权、审计/成本报表、备份恢复、统一日志、可用性测试。运维日常 90% 操作在这里完成。

## 2. 教学目标
学完本模块，学员应能：
1. 解释 AI 管理中心与 1Panel/Portainer 的本质区别（应用层统一鉴权 vs Docker 管理）。
2. 独立完成初始化（Global Admin、Keycloak Client、ai-platform-admin 角色）。
3. 熟练使用左侧菜单：Dashboard、各产品统计页、NewAPI 管理（成本/审计）、MCP 管理、集中认证、管理员账号管理、系统设置。
4. 独立完成**管理员分模块授权**（admin:<产品> 角色 + 产品侧真实开通）与撤销。
5. 使用备份恢复页、统一日志页、可用性测试、报告生成。
6. 理解 9 种界面语言与 Ghost 免登录机制。

## 3. 先修要求
- 完成 M01~M10（所有产品的接入前提）。

## 4. 课程内容与学时（共 4 学时，D8 上午）

| 节 | 内容 | 学时 | 类型 |
|---|---|---|---|
| 1 | 定位与架构（Keycloak 鉴权 / Admin API / Docker API）+ 菜单结构 | 0.5 | 讲授 |
| 2 | 初始化：Global Admin 环境变量、OIDC Client、ai-platform-admin 角色 | 0.75 | 实操 |
| 3 | Dashboard 与产品统计页逐页讲解（8 产品指标 + Docker 分组） | 0.75 | 实操 |
| 4 | 管理员分模块授权与撤销（含产品侧 provision 对照表） | 0.75 | 讲授+实操 |
| 5 | 运维功能：备份恢复/统一日志/可用性测试/报告/IM 告警 | 0.75 | 实操 |
| 6 | 系统设置/界面语言/Ghost 免登录 + 排错 | 0.5 | 讲授 |

## 5. 达标标准（A 级）
- 独立完成初始化并验证「未登录访问 302 到 Keycloak」。
- 能添加一个分模块管理员（如只给 Ghost 模块）并验证其在各产品中的真实权限。
- 能完成一次备份、一次恢复演练、运行可用性测试并解读结果。
