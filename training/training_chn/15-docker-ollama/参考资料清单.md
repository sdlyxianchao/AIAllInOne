## 四、自学建议
1. 先读《教材.md》→ 掌握平台内 8 个端口冲突、.env 必填项、`up -d` vs `restart` 的区别；
2. 实操：装 Docker Desktop→配置 .wslconfig→启动核心服务→部署 Dify→装 Ollama 拉 bge-m3；
3. 视频：Docker 一小时精讲（1.5 倍速）+ Windows Ollama 那篇；
4. 深入：Compose 官方 reference 按需查（volumes/networks/depends_on）；Ollama 学 Modelfile 与 REST API（平台语义缓存依赖 bge-m3）。
