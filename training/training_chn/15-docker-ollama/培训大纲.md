# Docker + Docker Compose + Ollama 培训大纲（M02 · 基础设施）

## 1. 课程定位
Docker Desktop（WSL2）是本平台唯一运行底座：41 个容器全部由 Docker Compose 编排。Ollama 是可选的本地模型运行时（提供 bge-m3 embedding 给语义缓存/知识库）。本模块是**所有后续模块的前置**。

## 2. 教学目标
1. 掌握 Docker 核心概念（镜像/容器/卷/网络）与常用命令（ps/logs/exec/restart/inspect/volume）。
2. 掌握 Docker Compose（服务/项目/环境变量/端口映射/卷挂载/网络），会读改 docker-compose.yml。
3. 能完成平台部署前置：.wslconfig 资源分配、创建 ai-platform 网络、复制 .env、启动核心服务、验证。
4. 会处理部署常见故障（端口冲突、容器 Restarting、镜像拉取慢/失败、WSL2 IPv6 问题）。
5. 安装 Ollama 并拉取 bge-m3（语义缓存/embedding 用），理解 host.docker.internal 访问宿主机。

## 3. 课程内容与学时（共 6 学时，D1~D2）
| 天/节 | 内容 |
|---|---|
| D1 上午 | Docker 概念 + 常用命令 + 镜像/容器/卷/网络 |
| D1 下午 | 环境准备：Docker Desktop 安装与配置、.wslconfig、目录结构、.env.windows 编辑、ai-platform 网络、固定内网 IP |
| D2 上午 | Docker Compose 深度：docker-compose.yml 结构、服务依赖、环境变量、端口冲突处理；启动核心服务（10 容器）+ 逐服务验证 |
| D2 下午 | Dify 独立部署（15 容器）+ 排错（GRAPH_ENGINE、WebSocket）；Ollama 安装 + bge-m3 |

## 4. 达标标准
- 独立完成 .env 配置与核心服务启动，41 个容器全部 Up。
- 能读懂 docker-compose.yml 任一服务块（端口/环境变量/卷/网络）。
- 会用 docker logs / exec / restart 排查容器问题。
