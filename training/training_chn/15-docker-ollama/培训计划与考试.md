## 考试考察（并入 D2 阶段测验）

### 理论（每题 2 分，共 20 分）
1. Docker 中持久化数据用（　）A. 镜像 B. 卷 Volume C. 网络 D. 容器
2. 修改 .env 后要让服务生效，必须（　）A. docker restart B. docker compose up -d C. 重启 Docker D. 不用管
3. 平台内 Prometheus 端口是（　）A. 9090 B. 9091 C. 3000 D. 3030
4. 容器间通过（　）互相访问 A. localhost B. 容器名（ai-platform 网络）C. IP 直连 D. 域名
5. WSL2 下 LiteLLM 宿主机访问应使用（　）A. localhost:4001 B. 内网IP:4001 C. 127.0.0.1:4001 D. litellm:4000
6. 容器访问宿主机服务（如 Ollama）用（　）A. host.docker.internal B. localhost C. 宿主机 IP D. gateway
7. Dify 独立部署后处于哪个网络（　）A. ai-platform B. dify_default C. host D. bridge
8. GRAPH_ENGINE_SCALE_UP_THRESHOLD 不修复会导致（　）A. 全部容器崩 B. Dify 4 个容器 Restarting C. 端口冲突 D. 网络不通
9. `.wslconfig` 中 memory 建议（　）A. 2GB B. 宿主机内存一半左右（最低 16GB）C. 随便 D. 越小越好
10. 镜像拉取慢的解决办法不包括（　）A. 配置镜像加速器 B. 使用代理 C. 加大内存 D. 换国内镜像源

### 实操（30 分）
1. 从零启动核心服务并逐项验证（curl/浏览器）。（20 分）
2. 用 docker logs 定位一个故意制造的容器故障并修复。（10 分）
