# Keycloak 培训大纲（M03 · 统一认证）

## 1. 课程定位
Keycloak 是 AI AllInOne 平台的**身份认证中枢**：所有 Web 产品（AI 管理中心、NewAPI、Dify、Ghost、Gitea、Grafana、Langfuse）都通过它实现单点登录（SSO）。掌握 Keycloak 是部署和运维本平台的前置条件。

## 2. 教学目标
学完本模块，学员应能：
1. 解释 Keycloak 在平台中的角色与核心概念（Realm/Client/User/Role/Identity Provider）。
2. 独立创建 Realm、用户、组、OIDC Client，并配置 Valid Redirect URIs。
3. 独立配置 AD/LDAP 用户联合（User Federation），完成域用户同步与登录验证。
4. 独立为各产品创建 OIDC Client 并接入 SSO（含 AI 管理中心、NewAPI、Grafana、Langfuse）。
5. 排查常见 SSO 故障（invalid_grant、redirect_uri 不匹配、LDAP 连不上、429 限流）。
6. 了解多身份源（AD + Entra ID + Google + SAML）共存与自动选择（Identity Provider Redirector）。

## 3. 先修要求
- 完成 M01（平台总览）与 M02（Docker 基础），能启动并访问 Keycloak 容器。
- 了解 OAuth 2.0 / OIDC 基本概念（授权码流程、token、scope）。

## 4. 课程内容与学时（共 6 学时）

| 节 | 内容 | 学时 | 类型 |
|---|---|---|---|
| 1 | Keycloak 概述与平台内角色（端口 9090、Realm enterprise-ai、统一管理员账号约定） | 0.5 | 讲授 |
| 2 | 核心概念：Realm / Client / User / Role / Group / IdP | 1.0 | 讲授+演示 |
| 3 | 管理台操作：创建 Realm、用户、组、角色；Credentials 设置 | 1.0 | 实操 |
| 4 | OIDC Client 配置：Client authentication、Standard flow、Redirect URIs、Web origins、Client Secret | 1.0 | 实操 |
| 5 | AD/LDAP 用户联合：Bind DN、sAMAccountName、Subtree、同步（重点 + 常见填错） | 1.5 | 讲授+实操 |
| 6 | 多身份源（Entra ID / Google / GitHub / SAML）+ 多身份源共存策略 | 0.5 | 讲授 |
| 7 | 排错专题：invalid_grant / redirect_uri / 429 / LDAP unknown_error / Account console 测试 | 0.5 | 讲授+实操 |

## 5. 达标标准（A 级）
- 独立完成「创建 Realm → 建用户 → 建 OIDC Client → 配置 NewAPI SSO 登录」全流程。
- 独立完成 AD 用户联合配置并通过 3 种方式验证（Account Console / Admin Console / 下游应用 SSO）。
- 能口述平台内各产品与 Keycloak 的接入方式对照表（见教材 5.5 节）。
