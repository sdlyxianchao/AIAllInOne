# 监控告警 培训大纲（M13 · Prometheus + Grafana + Alertmanager）

## 1. 课程定位
监控告警栈（Prometheus + Grafana + Alertmanager + cadvisor）提供**容器级资源监控与告警**：实时查看 41 个容器的 CPU/内存/网络/磁盘，容器宕机/超限自动告警并推送企业 IM。

## 2. 教学目标
1. 解释四组件各自角色与数据流（cadvisor 采集 → Prometheus 汇聚 → Grafana 展示；Prometheus → Alertmanager → AI 管理中心 → 企业 IM）。
2. 熟练使用 Grafana 大盘（已预置「AI All In One — 容器监控」面板），按容器/指标筛选。
3. 理解告警规则（monitoring/alerts.yml）与两个防误报过滤（name!=""、memory limit>0）。
4. 配置 IM 告警接收人（钉钉/企微/飞书 webhook 或企业应用发个人）。
5. 处理端口冲突等部署问题（9090→9091、3000→3030）。

## 3. 先修要求
M02（容器启动）；了解 Grafana 基本界面。

## 4. 课程内容（共 2 学时，D8 下午）
| 节 | 内容 |
|---|---|
| 1 | 架构与端口（cadvisor 8080 内部 / Prometheus 9091 / Grafana 3030 / Alertmanager） |
| 2 | Grafana 实操：登录（统一账号）、浏览大盘、按容器筛选、查看告警状态 |
| 3 | Prometheus：targets 状态、告警规则、PromQL 基础 |
| 4 | IM 告警配置：AI 管理中心 → 运维监控 → 监控告警 + IM 通知（多接收人/级别/发送规则/历史） |
| 5 | 常见问题（端口冲突、告警误报、webhook 配置） |

## 5. 达标标准
- 能从 Grafana 判断某容器内存是否超限；能解释两条防误报过滤规则。
- 能配置一个 IM webhook 并收到测试告警。
