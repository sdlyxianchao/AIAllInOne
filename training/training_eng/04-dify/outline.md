# Dify — Training Outline (M06 · AI Application Platform)

## 1. Positioning

The web AI app platform. Employees use AI in the browser (chat assistants, agents, workflows, text generation); admins configure model providers, build the **unified knowledge base (RAG)**, and manage members. Dify is the most employee-facing core product.

## 2. Learning Objectives

- Explain deployment (standalone ~15 containers, port 80, via NewAPI)
- Fix deploy issues (GRAPH_ENGINE, WebSocket, base64 password, reset-password)
- Configure model providers (LLM + embedding)
- Create chat/text/agent/workflow apps and publish
- Create knowledge base (high-quality index) + RAG apps + Knowledge API key
- Manage members
- Answer employee FAQ
- Integrate with MCP Gateway (M10)

## 3. Prerequisites

- M02, M04 (dify-key)

- Full flow "model provider → KB → RAG chatbot → publish"
- Can answer employee questions
- Can fix deploy-level faults
